PET INTERACTION DEMO

桌宠设计稿 · 动画与交互

配套 design/PET_INTERACTION_DESIGN.md。核心立场：桌宠是镜子不是闹钟——情感价值来自对每个动作的回应，不来自照料责任。本页可交互触发全部动效：左侧舞台直接拖拽精灵（悬挂物理）、按住 600ms 撸宠、点按钮看各状态与捕捉演出。

试这三件事：① 舞台里把精灵拎起来再放下；② 按「★ 捕捉演出」看掷球三摇星星（1.3 秒，可点击跳过）；③ 打开「生命感调度器」，什么都不做，看它自己眨眼、左右看。

生命微动作（调度器池 · 见 §4.4）

全部为「一次性事件 + 随机间隔」，不是循环动画——这是对「动效即信息」的显式豁免：它在过自己的日子。working 态调度器自动降频。

状态（镜子：反映你的工作）

捕捉演出时序（总 1320ms）

宽度按时长等比。点击「重播」在舞台与时间轴上同步演出；「跳过」演示用户随时可打断（点击舞台同样有效）。

点击跳过 = 回应不打扰原则：演出永不绑架用户时间
预备120ms · 蹲下蓄力
动作300ms · 掷球抛物线
高潮 · 三摇600ms ±14°×3
回应300ms · 星星+气泡

动效令牌 · 可爱三律

可爱不靠改精灵，靠时机与物理：落地必挤压 · 过冲必回弹 · 动作带预备帧。点击卡片看四种缓动的差异——禁用匀速与线性（那是机器，不是生物）。

--e-pop 弹出过冲cubic-bezier(.34,1.56,.64,1)
回弹感：撸宠、庆祝、松手回弹
--e-snap 快落轻冲cubic-bezier(.2,.9,.3,1.2)
落地、拖拽倾斜
--e-sway 摇摆往返cubic-bezier(.45,0,.55,1)
主循环跳跃、球摇、左右看
--e-sleep 呼吸cubic-bezier(.4,0,.6,1)
睡觉/待机呼吸（±2% 幅度）

注意力红线

情绪价值的边界——越过任何一条，陪伴就变成打扰：

同屏闪烁 ≤ 1
▼ 默认静态；紧急时只有优先级点/抖动占用名额
演出 ≤ 1.5s 且可跳过
点击即跳过；庆祝绑架时间 = 羞辱感倒置
永不主动索要注意力
一切演出是用户动作/设定事件的回应
激励只有正反馈
无连击惩罚、无失望表情、无损失厌恶
减弱动效双通道全关
微动作/演出/物理全部跟随，静态语义不丢
静景 ≤ 4 元素
精灵 / 色环 / 一句话对话框 / 2 钮药丸
