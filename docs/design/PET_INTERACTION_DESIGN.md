# 桌宠动画与交互设计 — 情绪价值（Pet Interaction Design）

> 范围：`src/PetApp.vue` 的动画体系、交互语义、信息密度、情绪曲线。
> 三项要求：**可爱 · 交互带来情绪价值与激励 · 只保留必要的信息**——外加本项目不可让渡的第四项：**注意力友好**。
> 配套设计稿：`pet-interaction-demo.html`（动画可交互触发）。
> 体验升级方案（输入响应/AI 对话/时刻台词/边缘栖息/语音/陪跑精灵/连胜演出）见 `docs/proposals/PET_EXPERIENCE_PROPOSAL.md`，配套设计稿 `pet-experience-demo.html`。

**一句话立场**：桌宠是**镜子，不是闹钟**。它的情感价值来自「对你每个动作的即时回应」，而不是「需要你照料的责任」——前者是陪伴，后者是注意力税。可爱不靠改精灵（素材是固定 GIF），靠**动画的时机与物理**（squash & stretch、过冲回弹、不对称小幅度）与气泡药丸的圆角软形状；激励不靠连击羞耻，靠**捕捉成功的那一刻被认真庆祝**。

---

## 一、设计立场：四条原则

1. **回应，不打扰**——所有演出（庆祝、问候、提醒）都是用户动作或用户设定事件的直接回应；宠物永不自发索要注意力：不主动开口（除用户设定的事件）、不打断（所有演出是用户动作的回应）、不废话（气泡一屏一义）。演出期间任意点击可跳过。
2. **动效即信息 + 生命感豁免**——循环动画纪律分两档：**信息动画**（进行中跳跃、紧急抖动、色环）只用于传达状态；**生命微动作**（眨眼、左右看）属于「它活着」这一状态本身，允许低频存在，但受调度器约束（§3.4）且跟随减弱动效开关。
3. **激励只有正反馈**——庆祝强度分级（普通捕捉/里程碑/收工），没有损失、没有羞耻、没有「宠物失望了」；宠物的「催」只存在于文案语气（急得直跺脚），永不绑定损失机制，没有 streak 断裂惩罚。
4. **一屏一义**——对话框同时只说一件事；常驻元素每个都要挣自己的位置（§4 信息极简）。

## 二、情绪设计总纲：三层情绪价值 × 一天的陪伴节奏

**三层情绪价值**（由浅入深）：

| 层 | 机制 | 例 |
|---|---|---|
| L1 即时反馈 | 每个操作 100ms 内有可感回应（juice） | 按下有按压位移、撸宠有弹跳、拖拽有悬挂物理 |
| L2 状态陪伴 | 宠物形象 = 你的工作状态的镜子 | 专注时它蹦跳陪跑、暂停变灰打盹、尾段它比你还急 |
| L3 成长记忆 | 完成与里程碑被「郑重对待」 | 捕捉演出、图鉴 +1、累计捕捉贺词、收工晚安 |

**一天的陪伴节奏**（全部被动触发，无主动打扰）：

```
晨间首现 ──→ 工作陪伴 ──→ 捕捉庆祝(×N) ──→ 收工演出 ───→ 睡觉
时段问候      专注/暂停/焦急    掷球三摇星星     今日图鉴圆满    系统闲置 zzz
```

- **时段问候**：每天窗口首次出现说一次（早/午/晚/深夜四档文案 + 主宝可梦名），只此一次，绝不重复。
- **睡觉**：系统输入闲置 ≥5 分钟（或用户从图鉴机收起后）→ 呼吸缩放 ±2% + zzz 气泡 + 轻灰度；任何输入（移动到精灵上/点击）→ 揉眼醒来（伸展 + 打招呼）。「你回来了」是零成本的高情绪时刻。

## 三、动画规范

### 3.1 动效令牌（`dex.css`）

```css
:root {
  /* 时长档 */
  --t-tap: 80ms;      /* 按压反馈 */
  --t-pop: 150ms;     /* 微动作单程（眨眼、抖动一帧） */
  --t-act: 300ms;     /* 事件动作单段（掷球、跳一下） */
  --t-scene: 600ms;   /* 演出单段（球摇一轮、落地回弹） */
  /* 缓动档（可爱=过冲与挤压，禁用匀速） */
  --e-pop: cubic-bezier(.34,1.56,.64,1);   /* 弹出过冲（回弹感） */
  --e-snap: cubic-bezier(.2,.9,.3,1.2);    /* 快落轻过冲 */
  --e-sway: cubic-bezier(.45,0,.55,1);     /* 摇摆往返（对称舒缓） */
  --e-sleep: cubic-bezier(.4,0,.6,1);      /* 呼吸（慢对称） */
  /* 幅度档 */
  --a-micro: 3px;  --a-hop: 7px;  --a-burst: 12px;
}
```

**可爱三律**（固定 GIF 上的动画层语法）：①落地必挤压（scaleY .85 → 回弹 1.05 → 1）；②过冲必回弹（位移/缩放用 --e-pop，不用 ease）；③动作带预备帧（跳之前 80ms 蹲一下）。像素风的「变形代替表情」是 GB 时代正统：眨眼=压扁、哈欠=拉长。

### 3.2 状态机

```
idle ──┬─ idle.calm（默认，慢呼吸+微动作池）
       ├─ idle.bored（无任务且闲置 >10min，微动作频率+，偶尔看向图鉴机方向）
       └─ asleep（系统闲置 ≥5min，zzz）
working（蹦跳主循环，微动作池降频）
paused（灰度+慢呼吸，不打盹到 sleep）
urgent（抖动，占用同屏唯一闪烁名额）
celebrating（捕捉演出，独占，1.5s 上限）
petting（撸宠，0.9s，可被打断）
dragging（拖拽悬挂物理）
```

### 3.3 事件演出编排（预备→动作→回应 三段式）

**★ 捕捉成功演出（核心品牌时刻，产品名就来自这句台词）**——总时长 ≤1.5s，点击可跳过：

| 段 | 时长 | 画面 |
|---|---|---|
| 预备 | 120ms | 点 ✔ → 精灵蹲下（scale .9），对话框收起，一个精灵球图标在对话框位置出现并蓄力下压 |
| 动作 | 300ms | 精灵球抛物线飞向精灵（CSS 抛物线：X 匀速 + Y 用 --e-pop）；精灵 opacity→0 |
| 高潮 | 600ms | 球落地挤压回弹，**摇三摇**（rotate ±14°，三轮，初代捕捉的经典节拍） |
| 回应 | 300ms | 咔哒——星星粒子爆开（4~6 颗，--a-burst 散射）+ 气泡「✔ 捕捉成功！记入图鉴」+ 换下一只精灵（若有） |

演出同时「图鉴 +1」由气泡文字承载，不加常驻元素。里程碑（累计 10/50/100…）升级为双排星星 + 贺词；**收工演出**（今日任务清零）再加一跳 + 「今日图鉴圆满，收工！」，仅此一次。

**问候/醒来/就寝**：均为「一段微演出 + 一句话气泡」（伸展 300ms / 揉眼 300ms / 呼吸渐弱 600ms），无粒子。

**拖拽物理**：拖动中精灵跟随但有 8° 倾斜 + 轻微滞后（跟随点在脚下，头甩动）；松手落定挤压回弹一次。让「拎着它走」本身好玩。

### 3.4 生命感调度器（idle 微动作池）

| 微动作 | 实现（GIF 变形魔法） | 权重 | idle.calm 频率 |
|---|---|---|---|
| 眨眼 | scaleY(0.15) 120ms | 5 | 常驻，8~15s 随机 |
| 左右看 | translateX ±4px + rotate ∓2°，停 400ms 看另一侧再回 | 3 | 20~40s 随机 |
| 翻面 | scaleX(-1) 600ms 后翻回（好奇地转身） | 2 | 60~120s 随机 |
| 哈欠伸懒腰 | scaleY(1.12)+translateY(2px) 慢起慢落 900ms | 1 | 3~6min 随机 |

规则：**working 态只保留眨眼且频率减半**（专注时不打扰）；同一时间只有一个微动作；与事件演出互斥；`prefers-reduced-motion` / 应用内开关直接全关（双通道）。微动作像它自己在过日子，但它是受调度的离散事件，不是循环动画，且永远静音——这是「循环动画只用于传达状态」与「生命感」的和解方式。

### 3.5 闪烁名额管理

对话框右下 ▼ **默认静态**（存在即语义）；仅当气泡为「未读新事件」（提醒/庆祝）时闪 3 次后停。同屏唯一闪烁名额优先让给紧急提醒——闪烁只作为「有新事」的信号。

## 四、信息极简：常驻元素规范

桌宠静景只有四类元素：**精灵 + 色环 + 一句话对话框 + 2 钮药丸**——每个都要挣到自己的位置。

| 元素 | 规则 | 理由 |
|---|---|---|
| 精灵 | 核心情绪载体 | — |
| 色环 | 全程被动显示 | 时间盲友好是刚需（被动信号原则）；SVG 细环不打扰 |
| 分类 | 不做常驻标签；开始任务时开场气泡说一次（「皮卡丘接下了『周报』！」），此后精灵图即分类 | 分类是低频信息，常驻标签是纯视觉税 |
| 对话框 | 一屏一义：同时只承载一件事（状态/事件台词二者其一）；提醒来时台词 + 动作条成对出现 | — |
| 番茄药丸 | 按状态 2 钮 + 上下文：运行中 ⏸ ✔；暂停态 ▶ 🍦 ✔；⇄ 切换收进右键菜单 | 换目标是低频操作，主操作时刻保持大目标 |
| 提醒动作条 | 保留（✔/⇨ 就近出口） | 消化「提醒→完成」流失链路，是信息不是噪音 |
| 今日进度 | 不占常驻，进晨间问候（「昨天捕捉 3 只，今天草丛里还有 2 只」） | 需要时问一句，平时不占屏 |
| 里程碑/连击 | 不加数字角标，只做一次性演出 + 图鉴机内贺词 | 激励走 L3 成长记忆层，不走常驻 UI |

## 五、交互语义表

| 手势 | 行为 | 情绪价值点 |
|---|---|---|
| 单击精灵 | 开/关快捷屏，展开前先播 150ms 跳一下（回应感） | 「它知道你点了它」 |
| 双击精灵 | 打开图鉴机 | — |
| 右键 | 菜单（含 ⇄ 切换目标），菜单项 ≤5 | 收纳低频 |
| 按住 ≥600ms | 撸宠专用入口：不打开任何面板，纯弹跳 + 台词 | 无副作用的纯情绪交互 |
| 拖拽 | 平移 + 悬挂物理（§3.3） | 拎着走的趣味 |
| 拖拽期间 | 微动作暂停，精灵「紧张小碎步」姿态（快速小幅摆动） | 它知道自己在被拎着 |
| 快捷屏内 ↑↓+Enter | 键盘流切换目标（与收音机一致） | 键盘用户不开面板也能切换 |
| 演出进行中点击 | 跳过演出 | 永不绑架用户时间 |

> 长按与拖拽的冲突处理：mousedown 后 600ms 内未移动超 4px 判定为长按（触发撸宠并取消拖拽预备）；一旦超阈值进入拖拽则不再触发。

## 六、注意力红线

同屏闪烁 ≤1 · 演出 ≤1.5s 且可跳过 · 永不主动索要注意力（一切演出是用户动作/设定事件的回应） · 激励只有正反馈（无连击惩罚、无失望表情） · 减弱动效双通道全关（微动作/演出/物理全部跟随，静态语义不丢） · 桌宠静景 ≤4 元素。
