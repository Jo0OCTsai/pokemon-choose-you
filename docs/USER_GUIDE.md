## 安装与首次启动

### 从安装包安装

- **macOS**：双击 `.dmg`，将应用拖入「应用程序」。首次打开若提示"无法验证开发者"，在「系统设置 → 隐私与安全性」点击「仍要打开」
- **Windows**：运行 NSIS 安装包（`.exe`），按向导完成安装
- **Linux**（实验性）：`.deb` / `.rpm` 用包管理器安装，或下载 `.AppImage` 加执行权限后直接运行（`chmod +x pokemon-choose-you_*.AppImage && ./pokemon-choose-you_*.AppImage`）。注意：桌宠窗口需 X11（Wayland 下置顶不可靠）；NVIDIA 显卡若白屏/黑块，启动前 `export WEBKIT_DISABLE_DMABUF_RENDERER=1`

### 首次启动

应用启动后会出现两个窗口：

- **图鉴机**（主面板）：任务管理、设置
- **桌宠**：常驻桌面的透明小窗口（透明置顶，不占任务栏）

建议第一件事：打开图鉴机 → 背包 → 通用 → 打开「开机自动启动」，以后登录系统桌宠自动出现。

> 数据全部存在本地，集中在归一化根目录 `~/.choose-you/`（agent 工作区在 `workspace/` 子目录，数据库在 `data/`、日志在 `logs/`；可用环境变量 `CHOOSE_YOU_HOME` 整体重定位），卸载重装不丢任务。旧版本数据在系统应用数据目录（macOS: `~/Library/Application Support/com.jotsai.pokemonchooseyou/` 等），新版启动时自动迁入新布局，旧目录保留不动，确认无误后可手动删除。
>
> **自动备份**：每天第一份快照存在 `~/.choose-you/data/backups/` 下（`VACUUM INTO` 压缩产物），默认滚动保留 7 份，可在 背包 → 通用 → 数据备份 调整份数、立即备份或从任意一份恢复（恢复立即生效、无需重启，会覆盖当前全部数据；秘钥在系统钥匙串不受影响）。
>
> **导出 / 导入**：背包 → 通用 → 数据导出 / 导入。全量 JSON（可在别的机器整体导入，秘钥不出文件）、任务 CSV（带 BOM，Excel 直接打开）、今日日报 Markdown（已完成/路线上/今日跟进三段，勾选框语法，可直接并入 Obsidian 等知识库）；产物都在 `~/.choose-you/data/exports/` 下，可一键打开目录。

## 核心概念（世界观）

**任务 = 野生宝可梦**。整个应用围绕一条捕捉链路：

```
遇见（新建） → 丢进草丛/加入路线 → ▶出发（派出宝可梦） → 捕获中（专注） → ✔已捕捉·登录图鉴
```

| 菜单 | 含义 | 类比 |
|---|---|---|
| **冒险** | 今天要完成的任务（进行中 + 今日到期） | 每日冒险 |
| **草丛** | 还没决定怎么处理的任务 | 野生宝可梦出没地 |
| **路线** | 按日期排期的未来任务 | 前进道路（Route） |
| **图鉴** | 已完成的任务 | 捕捉成就图鉴 |
| **收音机** | 自然语言快速捕捉 + 飞书消息里识别出的待办建议 | 收听电波 |
| **日志** | agent 会话历史（收音机分类 + 待办派发），按来源过滤、翻页回放 | 训练家的冒险记录 |
| **背包** | 应用设置：专注 / 词表 / 桌宠 / 显示 / Agent / 飞书 / 诊断 / 通用八个分区 | 训练家的背包（装备调校） |

每个任务分类绑定一只宝可梦（默认：工作=皮卡丘、学习=可达鸭、生活=妙蛙种子、健康=吉利蛋、兴趣=伊布），桌宠显示的精灵随当前任务的分类自动切换。分类可在背包里换装成 **PokeAPI 全部 1025 只**中的任意一只（内置 6 只离线可用，其余首次展示时联网加载精灵图）；没有任务时桌宠展示**主宝可梦**（背包 → 桌宠，不设置则跟随第一个分类），每只宝可梦还能写**专属台词**（点击桌宠时随机冒出）。旧版本里的「社交」「紧急」分类升级后自动移除（其下任务并入第一个启用分类），如仍需要可在背包里手动重建。

## 五分钟上手

1. **建一个任务**：切到**收音机**页，在顶部捕捉框用一句自然语言记录待办（如「明天下午 5 点交周报」），点 **⚡ 发报**——AI agent 自动判定内容、分类、标签、截止时间与优先级：
   - 判定为**新待办**时直接建好（5 秒内可 ↩ 撤销；撤回的消息回待处理，可改按建议捕捉或逃走）；有截止时间进**路线**，没有进**草丛**
   - 判定命中现有待办（重复 / 改期等变更 / 补充进展）时不重复建，改为在收音机生成**更新建议卡**或并入跟进，等你确认
   - 全局快捷键 `Ctrl/Cmd+Shift+K` 快速捕捉直达这个输入框；需要先在背包 → Agent 里配置好 AI agent
2. **开始专注**：在冒险页点任务的 **▶ 出发**——桌宠的宝可梦换装上岗，对话框显示「皮卡丘正在捕捉：xxx」，番茄钟自动开始倒计时
3. **随时可见自己在干嘛**：桌宠常驻显示当前任务；想换就把鼠标悬到精灵上、点浮现的 **☰ 钮**展开**快捷图鉴屏**，选中列表里的任务点「▶ 出发」，对话框会喊「就决定是你了！」
4. **完成**：点番茄钟上的 **✔**，任务变成「已捕捉」进入图鉴，今日进度条 +1
5. **等收音机送任务上门**：配置好飞书 + AI 后（见下文），飞书消息里的承诺和待办会自动变成建议，在收音机里逐条「◎ 捕捉 / ✕ 逃走」

## 就近可操作提醒

「提醒 → 打开应用 → 找到任务 → 完成」的链路常在第二步就流失。现在提醒触发时，桌宠的提醒气泡下方**直接带两个动作按钮**：

- **✔ 完成**：就地标记完成，精灵立刻庆祝
- **⇨ 推迟 10 分钟**：回写提醒时间，到点再敲一次门

就近消化，完全不需要打开主面板。动作条停留 60 秒或直到操作完成。
## 逾期 fresh start（反羞耻）

逾期堆积成「羞耻墙」是弃用生产力应用的头号触发点。冒险页的逾期任务**默认不逐条堆显**：折叠成一行低调的「🎒 昨天有 N 只溜走了（点开看看）」，点开才展开；行内「全部归草丛」一键清掉逾期时间让它们回草丛重新安排——任务不删、不指责。

背包 → 显示 → 「逾期任务展示」三模式：**折叠为一行**（默认）/ **自动归草丛**（每天首次运行时自动清逾期未开始任务的截止时间）/ **原样显示**。

## 「先试 5 分钟」启动模式

卡在「启动」上时，最短 15 分钟的番茄钟也是门槛。桌宠番茄钟未运行时（暂停或还没开始）有一个 **🍦 按钮**：开启一场明示「不成也没关系」的 5 分钟超短专注——精灵会说「就试 5 分钟，不成也没关系！」。

5 分钟到了**不自动接休息**：气泡换成「感觉对了就 ▶ 继续，今天到此为止也完全 OK」，继续或收工都被肯定——零挫败的入场券与退出门票。

## 环境化倒计时（时间感知）

数字倒计时读不进脑子——专注时桌宠精灵外圈有一圈**随剩余时间渐变的色环**（绿 → 琥珀 → 红），不需要读数字也能感觉到时间在流逝；进入尾段（剩 5 分钟或不足两成）精灵会**蹦跳加速**表现焦急。

**长番茄钟保护**（45/60 分钟档）：过中点响一声、剩 5 分钟响两声轻提示音（音量克制），既维持时间感知也防止过度专注；背包 → 专注 → 「轻提示音」可关。

## 相对截止时间（时间盲友好）

注意力对「9月15日 14:00」无感、对「还有 5 小时」有反应——任务卡上的截止时间默认显示为**距现在的距离**并按临近程度变色：

- 已逾期 X 分钟 / 小时 / 天 —— 红色加粗
- X 分钟后（1 小时内）—— 红色
- X 小时后（今天稍后）/ 明天 15:00 / 后天 09:00 —— 琥珀
- 周X（一周内）—— 常规
- X 天后（更远）—— 灰色

鼠标悬停可看绝对时间；背包 → 显示 → 「相对截止时间」可关闭回绝对显示。

## 每周复盘（训练家复盘）

图鉴页右上角 **🧢 复盘** 打开五步向导：

1. **总览**：本周捕捉数 / 专注分钟 / 路线上 / 草丛里的任务量，按分类的捕捉条形图
2. **路线复盘**：逐站过一遍路线上（含进行中）的任务——保留 / ✔ 完成 / 归草丛（清截止时间）/ 🚪 逃走，就地处置
3. **草丛归位**：勾选不再想做的草丛任务批量放生，或全选一键清理
4. **标签体检**：AI 复核标签词表——近义合并建议（合并进使用更多的同名标签）、僵尸标签（90 天未用且非手建，建议放生）、新维度建议（采纳即建维度并迁移既有标签）；每条都可逐个处理或忽略，未配置 AI 时展示本地相似度预筛结果
5. **收尾**：记录本周已复盘，显示本周总收服数

**提醒**：背包 → 通用 → 每周复盘提醒，可选提醒日（默认周一）；到点发系统通知，每周一次。主流任务应用（除 OmniFocus 外）没有内置回顾，带提醒的复盘是本应用的差异化能力。

## 桌宠详解

### 布局（初代战斗界面）

精灵在上、全宽对话框在下（右下角 ▼ 闪烁）、番茄钟药丸在底部。

### 操作

| 操作 | 效果 |
|---|---|
| **按住拖动** | 移动桌宠窗口（移动超过 4px 才算拖，不会误触）；拖到屏幕底缘/任务栏附近松手，精灵会**坐下栖息**（动画幅度减半，拖走即站起） |
| **单击精灵** | 随机搭话——蹦跳一下冒出台词（写过专属台词的宝可梦优先说自己的） |
| **双击精灵** | 打开图鉴机主面板 |
| **悬停精灵** | 浮现 **☰ 钮**，点它展开/收起**快捷图鉴屏**（单击精灵不再触发展开，防止误触弹大面板） |
| **长按精灵 ≥600ms** | 撸宠——纯弹跳 + 台词，不打开任何面板 |
| **右键精灵** | 菜单：打开图鉴机 / 快捷图鉴屏 / ⇄ 切换目标 /（配置了 AI 时）💬 和精灵聊聊 / 暂停当前任务 / 隐藏桌宠 |
| 番茄钟 ⏸ / ▶ | 暂停 / 恢复当前任务计时 |
| 番茄钟 ✔ | 完成当前任务 |
| 番茄钟 🍦 | （暂停态出现）开启「先试 5 分钟」超短专注 |

### 桌宠状态

- **工作中**：精灵跳跃动画，开始时气泡说「xx正在捕捉：任务名」
- **暂停**：精灵变灰
- **紧急提醒**：对话框抖动 + 红色系统通知「‼ 训练家，快看快看！」
- **普通提醒**：气泡换文案 + 系统通知，15 秒后自动恢复
- **番茄结束**：抖动提示 + （可选）系统通知；配置了短休息则自动进入 ☕ 蓝色倒计时，休息完提示「点 ▶ 开新一轮番茄」

台词气泡是**瞬态**的（VPet 范式）：显示时长随文本长度自适应（基础 3.5 秒、每字 +0.12 秒、封顶 12 秒），说完自动淡出，**悬停可暂停**倒计时、**点击立即收起**——不说话时对话框完全让位。桌宠的常驻状态由番茄钟药丸承载，不靠常驻文字。

### 陪伴小剧场（背包 → 桌宠 · 桌宠陪伴）

环境感知层的小能力，全部**默认关闭/静音**，按需打开：

- **输入响应**：桌宠感知得到你打字的快慢（只感知快慢，**不知道你打了什么**——事件只含每秒计数）。空闲时打字，精灵会小幅回应；子开关「专注时也响应」开启后，专注中的蹦跳节奏会轻随打字速度（最多快 10%）。macOS 首次开启需要辅助功能权限（背包里有指引）。
- **💬 和精灵聊聊**：配置了 AI agent 后，右键菜单出现对话入口。对话框原位展开，可以直接问「今天还剩什么？」「这周捕捉了多少？」——回答带任务上下文、最多两句、只答不执行（涉及操作会请你回主面板确认）。Esc 或 ✕ 收起。
- **桌宠语音**：里程碑贺词、收工、精灵生日、对话回答这四类「郑重时刻」用系统语音说一句（默认静音；走系统本地 TTS，不联网）。
- **陪跑精灵**：一场专注满 25 分钟时，图鉴里的一只宝可梦会走进来在旁边坐下安静陪你（点它就挥手告别；一场专注最多来一次，全程不说话）。

不用设置的自动彩蛋：整点/深夜/周五晚/精灵生日（首次见面纪念日）的**时刻台词**每天各说一次；**连胜捕捉演出**——连续多天每天都有捕捉（允许漏一天）且今天捕获的是第一只时，普通捕捉演出升级为双精灵球交替三摇。

## 图鉴机详解

### 任务条目（图鉴条目卡）

每张卡片包含：条目编号 `No.013`、分类精灵图、标题、属性徽章、优先级圆点（紧急=红闪）、截止/提醒时间、专注时长、来源。

进行中的任务有黄色描边 +「♪ 捕获中」角标；已完成的变 LCD 灰绿色、标题划线、精灵剪影化，可「↩ 撤销」。

**右键任务卡**：出发/暂停、加入路线、编辑、完成、逃走、放生（删除）等动作都在右键菜单里，与卡片按钮一一对应；菜单底部还有「查看详情」和「复制标题」。输入框右键则是熟悉的剪切/复制/粘贴/全选。

### 捕捉进度条

冒险页右上角 `CAUGHT 5/8`——今日完成数/总数，一眼看到今天的战绩。

### 快速捕捉（收音机）

新建待办的唯一入口在**收音机**页顶部：一句自然语言（「明天下午 5 点交周报」「周五前给老妈订生日蛋糕 #生活」）→ **⚡ 发报**。AI agent 判定标题、分类、标签、截止时间、优先级与备注：新待办直接建好（识别出截止时间进路线，否则进草丛；5 秒内 ↩ 可撤销）；命中现有待办则不重复建，生成更新建议卡或并入跟进，在收音机里等确认。判定失败的消息保留为「AI 判定失败」——可单条或整组**一键重判**（重新送 AI；agent 超时被杀但判定已落库的会自动收下），也可强制捕捉或逃走。`Ctrl/Cmd+Shift+K` 全局直达。

需要先在 背包 → Agent 里配置并启用 AI agent；捕捉会按次记入 agent 会话记录（「日志」页可回放）。

## 背包（设置中心）

背包（设置）分八个分区（上选单下内容，保存按钮吸底）：

| 分区 | 内容 |
|---|---|
| **🍅 专注** | 番茄钟开关、时长（15/25/45/60 分）、短休息（关/5/10 分）、番茄完成通知 |
| **🗂 分类与标签** | 分类增删改，每行可给分类换宝可梦（PokeAPI 全量 1025 只，按名称/编号/英文名搜索）；「放生」分类时其任务自动归入第一个分类。标签按**维度**分组管理（内置项目/场景/人物/主题，可增改）：项目维度单选、每条待办至多 3 个标签、每维度有数量上限。AI 从消息生成待办时会挑选合适的标签；某维度没有贴切选项且消息有明确依据（出现的项目名/人名/群名）时会提议新标签——建议卡上标「＋」，**接受建议时才创建**，不接受不进词表。同页「标签维度」卡：维度改名/上限/停用（key 与单多选建后不可改，AI 协议稳定标识；停用后该维度不进新建与 AI 选项） |
| **🐾 桌宠** | **主宝可梦**（空闲桌宠展示）；**宝可梦台词**（每只可写专属语录）；**输入响应**（空闲时随你敲键盘的节奏做小回应，macOS 需授权辅助功能，可限定专注时也响应）；**桌宠语音**；**陪跑精灵**（专注满 25 分钟来陪坐） |
| **👀 显示** | **语言**（简体中文/繁體中文/English，即时切换）、日期格式、时间制式（带预览） |
| **🤖 Agent** | AI agent 配置、项目派发路由（按项目标签绑定 agent 与工作目录，见「待办派发」一节）、待办派发自动化 |

## 诊断中心

背包 → 诊断，一条页面看清两条外部链路（飞书电波 / AI Agent）的运行状态：

- **集成健康**：每条链路展示三档状态（正常 / 降级重试中 / 故障）、上次成功时间、下次轮询时间、连续失败次数、最近错误；飞书还显示收音机里待确认建议的积压数。失败会自动指数退避重试，也可点「立即拉取 / 立即同步」手动触发。

## 对接飞书（收音机）

让飞书消息里的待办自动变成图鉴机里的建议。**全程免费、无需公网服务器。**

消息拉取走**官方 lark-cli**（[larksuite/cli](https://github.com/larksuite/cli)）：消息以**你的身份**拉取，私聊和群聊都能听见，**不需要把机器人拉进任何会话**；lark-cli 的自建应用与授权凭证都由它自己保管（**不进本应用数据库**），应用内无需填写任何飞书配置。

> WebSocket 实时事件：lark-cli 提供 lark-event 订阅能力，但常驻桌宠应用管理长连接生命周期（断线重连、休眠唤醒、多实例）复杂度尚高，当前版本按设置的间隔轮询；拉取已按命令抽象，后续可平滑接入。

### 第一步：安装 lark-cli

```bash
npm install -g @larksuite/cli
```

### 第二步：授权登录

背包 → 飞书，点「**授权登录**」——应用会在系统终端里运行 lark-cli 的登录流程（首次会先 `lark-cli config init --new` 在浏览器里为你自动创建自建应用，再 `lark-cli auth login --domain im --recommend` 完成用户授权；之后只跑登录命令）。在终端里完成授权后回到背包页点「测试飞书连接」。系统没有可用终端模拟器时（如未装桌面终端的 WSL），错误提示会给出可手动粘贴的完整命令。

### 第三步：启用轮询

1. 打开「启用后台轮询」，选轮询间隔（默认 2 分钟）
2. 点「测试飞书连接」——提示"连接成功（lark-cli）：已授权「你的名字」，可见 N 个会话"即通

### 使用

之后每轮轮询以你的身份拉取新消息，按聊天语境分别处理：

- **你私聊发给机器人的消息**（与机器人/助手的单聊）——当作你给自己记的备忘/指令，交 AI 判定（机器人的回复只作上下文）
- **你发给自己的会话**——同样当作备忘，交 AI 判定
- **别人私聊发给你的消息**——交 AI 判定（你回复的消息只作上下文）
- **群聊里别人发的消息**——交 AI 判定（你自己的消息只作上下文）

AI 判定时会带上**同会话 30 分钟内的近期上下文**与消息来源（私聊/群聊/机器人），帮助理解指代与时间。**判定链路全链路假名化**：送大模型前，所有人名替换成稳定代号（同代号=同人、「我」=你本人），消息头附「@我（显式）/ 疑似@我」的确定性提及标注辅助归属判断；真名只存在本地数据库，判定落库时自动还原——模型永远看不到真实姓名。每条建议都会附**判定理由**与**置信档位**（高/中/低——低置信的建议值得多看一眼）。判定动作有四种：

| 动作 | 什么时候 | 去向 |
|---|---|---|
| **新待办** | 消息里出现新的任务/承诺/会议 | 收音机生成建议卡，**◎ 捕捉**（进草丛）或 **✕ 逃走** |
| **更新建议** | 消息是对现有待办的变更（改期、调整优先级、换标题、变更要求） | 收音机生成更新卡，列出要改的字段，**◎ 应用更新** 后打补丁到原待办 |
| **跟进记录** | 消息是现有待办的补充信息/进展/确认 | 自动记入该待办的跟进记录（可在编辑弹窗查看） |
| **无动作** | 闲聊、纯信息、重复提及 | 仅留档 |

逃走时可以顺手选一个**原因码**（已有类似待办 / 不是给我的任务 / 建议内容不对 / 闲聊噪音 / 已过期 / 其他）——这些反馈连同建议与判定模型一起存在本地，用来帮 AI 越判越准；不选直接逃走也完全可以。批量逃走可先用旁边的下拉统一选原因。已逃走的消息默认收起成一组，展开后每条**亮出 AI 原判与逃走原因**（当时模型判了什么、你为什么放走），后悔了点「↩ 恢复」随时拉回待处理——逃走不删数据。

只有你确认过的才会创建/修改任务，AI 不会自作主张（跟进记录是追加信息，无破坏性，故自动记录）。

富文本消息会转成可读文本（@人还原成姓名、链接带地址、图片/文件/语音以 `[图片]` `[文件:名字]` 等占位）；纯媒体消息只作上下文，不送 AI。群成员姓名通过群成员接口解析并本地缓存。

### 会话过滤（哪些会话参与拉取）

**默认跟随飞书免打扰**：你在飞书设了免打扰的会话整会话跳过（一条不拉）。这个默认可以逐会话接管——打开 背包 → 飞书 → 「会话过滤」卡片：

- 每个会话三态可选：**跟随**（默认，按飞书免打扰决定）/ **拉取**（总是拉取——哪怕在飞书免打扰了，重要会话不再静默消失）/ **过滤**（总是跳过——飞书侧没设免打扰的噪音会话也能屏蔽）。
- 手动设置后**以本应用为准**，飞书侧再改免打扰不影响该会话；改回「跟随」即交还决策权。
- 行上的状态 chip 显示下一轮的实际效果与依据（手动 / 跟随 / 降级——降级 = 该轮免打扰查询失败，按现状降为不过滤）。
- 更改**立即生效**（无需点「保存设置」），下一轮拉取起作用；解除过滤只收新消息，不回补被过滤期间的历史。

> 断网自动退避重试（间隔翻倍，上限 8 倍），恢复后自动追平，日志可查。

## 配置 AI Agent CLI

用于飞书消息的待办识别与判重。改为调用本地 **AI agent 命令行工具**（无头模式），不再走 AI 接口：

| Agent | 命令 | 无头调用（应用预设） | 历史记录参数 |
|---|---|---|---|
| Claude Code | `claude` | `-p {prompt} --allowedTools Bash(pk:*) --output-format json`（JSON 信封带回 session_id / 成本，会话回链自动落库） | `--resume` |
| OpenCode | `opencode` | `run {prompt}` | （TUI 自带会话列表） |
| pi | `pi` | `-p {prompt}`（bash 等工具默认可用，无权限弹窗） | `-r`（选择器；按会话 id 恢复时应用自动换成 `--session <id>`） |
| 其他 | 任意 | 自定义 | 自定义 |

> 会话历史说明：claude 的无头（`-p`）会话**不出现在交互选择器里**，只能按会话 id 恢复——
> 应用已自动记录每次无头调用的 session_id，任务详情抽屉「Agent 执行」区的回放入口
> （`claude --resume <id>`）即走此路径。pi 无头派发按 `--session-id <id>` 续接（该 id 不存在时按 id 新建，首轮由应用预生成）。

**SSH 远程执行**：agent CLI 不在本机时，在 agent 配置里勾选「SSH 远程执行」并填目标（`user@host`，可指定端口与私钥路径）。实际执行的命令是 `ssh -o BatchMode=yes -o ConnectTimeout=10 [-i 密钥] [-p 端口] user@host -- <command> <args...>`：

- 提示词一律走**标准输入**转发（`{prompt}` 占位符参数自动剔除，如 `claude -p {prompt}` 远程执行为 `claude -p` + stdin），避免 ssh 拼接 argv 后被远端 shell 打碎
- 需要先配好**公钥免密登录**（BatchMode 不允许交互输密码）；连接超时 10 秒，整次调用仍受该 agent 的超时设置约束
- 「历史记录」入口同样经 ssh 转发，`claude --resume` 等交互界面照常可用
- 环境变量 `PK_SSH_BIN` 可覆盖 ssh 客户端程序名（默认 `ssh`）
- **远程 agent 使用 pk 工具（一键配置）**：数据在本机，远程放一个经**反向隧道**回连的透传 shim——应用的每条 ssh 连接把远程的 `127.0.0.1:隧道端口` 转回本机 sshd，远程 agent 经 shim 回本机执行 pk；**本机不开放任何入站端口**。用户只需两步：
  1. **本机开启 sshd**（隧道终点，仅本机回环可达即可，防火墙无需放行）：macOS 系统设置 → 通用 → 共享 → 远程登录；Windows 安装并启动「OpenSSH SSH 服务器」可选功能；Linux `sudo systemctl enable --now sshd`
  2. agent 的 SSH 配置区点 **「一键配置远程 pk」**（隧道端口默认 10022）

  一键配置自动完成（全程幂等，可重复点击）：生成/复用专用密钥 → 公钥以 `restrict,command=` 受限条目装配本机 `authorized_keys`（该密钥只能回连执行 pk，开不了 shell）→ 私钥推到远程 `~/.ssh/pk_shim` → 预信任 `[127.0.0.1]:端口` 的主机指纹（shim 走 BatchMode，首次连接的交互确认必须预先写入 known_hosts 才不会失败）→ 安装 shim（内嵌本机 pk 绝对路径）到远程 `~/.local/bin/pk` 并保障登录 shell 的 PATH → 把隧道端口写回 agent 配置 → 开一条真实隧道端到端验证（远程 `pk --version` 应返回本机版本）。失败会指明停在哪一步与修法；成功后可再点「测试」跑工具探针。手工等价命令：`pk remote shim --host <本机用户名>@127.0.0.1 --port 10022`；排障可跑 `pk doctor --ssh <远程>`。

  > 同一远程机器配多个 agent 时请保持相同的隧道端口（shim 按端口回连；常驻隧道按「主机+端口+密钥+隧道端口」去重，多个 agent 共享同一条连接）。

- **常驻隧道（推荐开启）**：默认模式下隧道随应用的调用建立、随调用拆除——两次调用之间或应用空闲时，远程（如 tmux 常驻会话、手动 ssh 上去的会话）调 pk 会失败。SSH 配置区开启**「常驻隧道」**后，应用驻留期间自己维持一条 `ssh -N -R` 长连（keepalive 10s×3 检出死连接约 30 秒内自愈；远程端口被占即退出重连，不会出现「连接活着但隧道没建」的假隧道；断线按 1s→30s 指数退避重连），远程**任何进程**随时可调 pk。状态行实时显示（已连通/建立中/重连中，重连态附 ssh 报错尾行）；应用的无头调用仍照常按需带 `-R`，作为常驻隧道断线空窗期的兜底。应用退出隧道即收起（期间远程调 pk 会失败，启动应用即恢复）。
- **远程调用效率与环境透传**：shim 带 **ControlMaster 连接复用**（首次调用建主连接，会话内后续调用毫秒级返回）——旧版 shim 需重跑一次「一键配置远程 pk」升级；无头调用注入的 `PK_DISPATCH_TASK`（派发回传）与 `PK_LOG_FILE`（执行轨迹写回应用日志）经远端命令行带到远端、由 shim 转发回本机侧 pk 照常生效（Windows 本机的 sshd shell 是 cmd，无 env 命令，此透传不生效，其余功能不受影响）。

背包 → Agent → AI Agent CLI：

1. 选预设 → 点「＋ 添加 Agent」（也可自定义命令与参数）；**同类型可加多个**（如本地一个
   Claude Code、远程一个），重名自动加序号后缀（Claude Code 2），每个 agent 的名字行
   可自由改名；
2. 可配置多个：用单选「用于收音机分类」指定当前生效的 agent（选项带 · SSH 徽标区分
   本地/远程），其余作为备用；
3. 点「测试」会真跑一次工具探针（`pk context`），一次验证命令可用、工具白名单、PATH 与数据库整条链路；
4. 点「历史记录 ↗」会在新终端中打开该 agent 的会话历史（历史由 agent 工具自己保存；
   远程 agent 经 ssh 转发，交互界面照常可用）；
5. 「pk 技能」行的**检查 / 安装同步**：一键把 pk 使用技能装进该 agent 的技能目录并
   对比版本（本地直写；远程 agent 经 ssh 写**远端机器**的目录——技能是给 agent 读的，
   必须装在 agent 实际运行的那台机器上）。

要点：

- **{prompt} 占位符**：附加参数中的 `{prompt}` 会被替换为完整提示词；不写占位符则提示词经标准输入传入（适合长提示词）。
- **工作目录**：agent 及其工具（读写文件、git 等）的相对路径基准，支持 `~` 前缀；留空为应用专属工作区 `~/.choose-you/workspace`（不存在会自动创建；根目录下的 `data/`、`logs/` 是应用自留地，不落在 agent 可写范围内）。应用启动方式不同、GUI 进程的默认目录不可控（Dock/Finder 启动时是 `/`），所以总会显式指定，不会「随机」落盘。SSH 远程模式下填的是**远程机器上的路径**，调用与「历史记录」终端会话都会先切到该目录；远程留空则落在远端登录目录（远端 `$HOME`）。
- **超时**：agent 启动 + 推理比直连 API 慢，默认 120 秒，可按需调大。
- Windows 下 npm 全局命令（`claude.cmd` 等）会自动经 `cmd /C` 回退启动，无需绝对路径。

**结果回收（经 pk 落库）**：判定结果统一由 agent 通过 pk 命令行写回数据库——先跑 `pk context` 拿判重上下文，再用 `pk suggest batch` 把整批判定一次性提交，应用直接回读，不解析模型输出的文本（判定结果带强校验）。本机调用时应用会把随附 `pk` 所在目录自动注入 agent 子进程的 PATH，无需手动配置；远程 agent 则用上文的「一键配置远程 pk」。要求 agent 无头模式下允许执行 pk 命令：

- Claude Code：应用预设已带 `--allowedTools Bash(pk:*)`（`:*` 为前缀匹配语法；参数按空白切分，**不要加引号**——引号会变成值的一部分），自定义参数时记得保留
- OpenCode：在其权限配置中允许执行 `pk` 命令
- pi：工具执行默认无权限弹窗，无需额外参数
- 工具循环比单轮输出慢，建议把超时调大到 300 秒左右

## 待办派发给 Agent（按项目标签路由）

挂了「项目」维度标签的待办，可以一键派发给 agent 在指定工作目录（git 仓库）里处理——在新终端里启动 agent 并自动注入任务命令，人可以随时观察或接管。设计细节见 [AGENT_DISPATCH_PROPOSAL](proposals/AGENT_DISPATCH_PROPOSAL.md)。

**一次配置：给项目标签设「派发设置」**（背包 → Agent →「项目派发」卡片，改动即时保存，不需要点页面顶部的「保存设置」）：

- **agent**：该项目的待办优先派给谁（不指定 = 全局默认，即「用于收音机分类」选的那个）
- **工作目录**：agent 处理该项目的工作目录（按 agent 位置解释：本地 agent 填本机路径，SSH 远程 agent 填远端路径，支持 `~` 前缀；留空 = agent 自身的工作目录配置）
- **项目上下文**：技术栈、注意事项等，会拼进派发给 agent 的任务提示词

**派发**：打开待办的详情抽屉（点任务卡片），「⚡ Agent 派发」区显示路由结果（agent · 本机/SSH · 目录 · 来源），可临时改选其他 agent，点「⚡ 派发」即在新终端窗口启动：

- **本地 agent**：终端里 `cd 工作目录` 后启动 agent，任务提示词作为首条输入（claude 交互模式支持首条消息参数；opencode 等的 TUI 若不接受首条参数，命令会显示在终端里可手动粘贴）
- **SSH 远程 agent**：终端跑 `ssh -tt <host> "tmux new -A -s pk-<任务id> -c <工作目录>"`（attach-or-create，**断开重连会话不丢**，随时重开终端接回），应用另起一条 ssh 把任务命令经 `tmux send-keys -l` 字面注入并回车；远端没装 tmux 时降级为直接启动（断开即结束，会提示安装 tmux）
- 每次派发都会在「Agent 执行」时间线落一条记录（命令摘要 + tmux 会话名）；全部会话（含收音机分类）集中在「日志」页，可按来源过滤、翻页回放；任务提示词里的标题/详情/跟进记录/项目上下文做了**定界隔离**（声明为数据非指令），防止待办正文里的注入内容指挥 agent

要求与提示：远程交互派发依赖**免密登录**（与无头分类同一前提）；同一任务重复派发会在同一个 tmux 会话里注入新命令——若上个 agent 的 TUI 还开着，请先退出再派发，否则命令会被敲进 TUI 的输入框。

**无头通道（跑完自动回传）**：抽屉的通道下拉切到「无头」再派发，agent 在后台无头执行，跑完按退出码自动判定（claude 还会解析 JSON 信封取会话 id 与成本；重派时自动 `--resume` 上一轮会话续接上下文）。适合短任务与批量；长任务建议交互通道。派发用的参数会自动剔除分类预设的只读白名单（`--allowedTools Bash(pk:*)`）——派发要读写仓库。

**派发状态机与回传**：每次派发把任务置为「执行中」，结束回传后变「已回传 / 失败」（抽屉里带状态徽章；列表卡片有 ⚡ 小标）。回传途径：

- 无头：退出码 + 信封自动判定，无需 agent 做任何事
- 交互/其他 agent：agent 处理完后执行 `pk dispatch done --task <id> --note 摘要`（无法完成用 `dispatch fail`；pk 技能里有完整说明，claude 还可配 Stop hook 自动回传）
- agent 没回传时，抽屉里的「标记完成 / 标记失败 / 重置」可手动收口（重置救卡死的执行中）

**自动派发（默认关闭）**：背包 → Agent → 「待办派发」开启「自动派发」后，**到期未开始**且**项目标签明确指定了 agent** 的待办每 60 秒扫一次、排队无头执行（完成/失败发系统通知）；「每机器并发上限」对本机与每台 SSH 主机分别生效；「worktree 隔离」开启后每次派发在 `../<仓库>-pk-<任务id>` 工作树（分支 `pk-<任务id>`）里执行，多个待办派到同一仓库互不踩踏，完成后人工合并。已完成/失败的派发不会自动重派，避免失败循环。

## pk 命令行（供 AI agent 与终端使用）

应用随包分发 `pk` CLI，全部输出 JSON，可直接给 AI agent 工具（claude code / opencode / pi…）当工具用，也可自己在终端操作：

```bash
pk task list [open|done|today|all]   # 任务列表（默认 open）
pk task get 3                        # 任务详情（含跟进记录）
pk task search 关键词                 # 搜标题/备注/跟进/标签
pk task create --title "交周报" --due "2026-09-13T18:00" --tags 重要
pk task update 3 --priority high --due ""   # 空串清空截止时间
pk task done 3 && pk task start 5    # 完成 / 开始（全局唯一进行中）
pk note add 3 对方确认周五交付 --source ai
pk tag list                           # 标签列表（含维度）与维度配置
pk tag create 新项目 --dimension project --description 描述   # 新建标签（缺省 topic 维度）
pk context                           # 当前时间 + 未完成待办 + 分类 + 标签与维度（AI 判重上下文）
pk task create --title 交周报 --dry-run     # 只校验回显不落库（task update/delete 同）
pk suggest todo --message <消息id> --title 交周报 --due 2026-09-13T18:00  # 提交 AI 判定建议（写建议列待用户确认）
pk suggest batch --agent claude-code < suggestions.json                  # 批量提交（stdin 传 {"results":[...]}，整批校验）
pk dispatch done --task 3 --note 修复完成并补回归                        # 派发状态回传（无法完成用 dispatch fail；--task 缺省读 PK_DISPATCH_TASK）
pk remote shim --host <本机用户名>@127.0.0.1 --port 10022 > pk    # 手工生成远程透传脚本（应用内有「一键配置远程 pk」）
pk doctor                            # 环境自检：数据库/schema/技能安装，每项带修复建议（--ssh <host> 加测远程 pk）
pk help --json                       # 机器可读的命令目录（供 agent 编程化发现）
pk help                              # 完整命令说明
```

- **技能一键分发**：`pk skill install claude-code` 把 pk 使用技能装进 agent 的技能目录（claude-code → `~/.claude/skills/`，opencode → `~/.config/opencode/skill/`，pi → `~/.pi/agent/skills/`），含主文件 SKILL.md 与 references/ 引用文件（完整参数表、无头分类工作流），带版本标记、跨版本重装会提示更新；其他 agent 用 `--dir <目录>` 指定落点，或 `pk skill show` 打印全部内容自行粘贴。背包页 agent 配置里的「pk 技能 · 检查 / 安装同步」按钮走同一套逻辑，且远程 agent 会经 ssh 装到远端机器的对应目录
- **agent 友好性**：`--dry-run`（task create/update/delete 只校验回显不落库）、`task list --limit`（默认 50 条，`truncated` 提示用 search 收窄）、`help --json`（机器可读命令目录）、`doctor` 环境自检——检查数据库存在性、schema 版本、完整性、WAL 并发、context 读链路与技能安装版本，每项 ok/warn/fail 并附 `fix` 修复建议（有 fail 退出码 1）；远程部署排障加 `pk doctor --ssh <user@host>`，端到端验证 ssh 免密 → shim 在 PATH → 回连本机整条链
- **会话回链与成本记录**：agent 代办后 `pk session log --task 3 --agent claude-code --session <id> --cost 0.12 --duration-ms 61000` 落一条会话；任务编辑弹窗的「Agent 执行」区展示每次的时长 / 成本 / 退出码（含收音机分类调用），有会话 id 的可一键在终端回放转录（`claude --resume <id>`）
- 与桌面应用共用同一个 SQLite 库（WAL 并发安全），操作同样写入审计日志；
- 环境变量 `PK_DB` 可指定独立数据库路径（`pk init-db` 可引导空库）；默认库随应用走 `~/.choose-you/data/pokemon-choose-you.db`，`CHOOSE_YOU_HOME` 可重定位归一化根；
- 安装位置：应用安装目录（与主程序同级），加入 PATH 后即可全局使用。

## 常见问题

**Q：桌宠点击没反应？**
按住拖动超过 4px 才算拖拽，原地点击才会触发交互；另外确认点的是精灵/对话框区域，番茄钟按钮和快捷屏内部不触发拖拽。

**Q：中文/emoji 显示成方块？**
WSLg 环境缺字体。下载 [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk) 和 Noto Color Emoji 放入 `~/.local/share/fonts`，执行 `fc-cache -f`。macOS / Windows 无此问题。

**Q：收不到系统通知？**
- macOS：系统设置 → 通知 → 就决定是你了 → 允许
- Windows：设置 → 系统 → 通知 → 开启应用通知
- 应用内：背包 → 专注 → 「任务提醒通知」需开启

**Q：飞书拉不到消息？**
依次检查：① 终端里 `lark-cli auth status` 显示已登录（未登录时在背包 · 飞书分区点「授权登录」重跑一遍）；② 终端里 `lark-cli config show` 正常（报 not_configured 就先 `lark-cli config init --new`）；③ 日志 `~/.choose-you/logs/` 里有 `feishu poll failed` 具体原因；④「测试飞书连接」是否成功。

**Q：lark-cli 登录过期了怎么办？**
点一次「授权登录」（或在终端跑 `lark-cli auth login --domain im`）重新登录即可；凭证由 lark-cli 自管，应用无需其他操作。

**Q：AI 分类结果不准？**
换一个能力更强的 agent / 模型（agent CLI 内自行配置），或在 agent 中调整模型档位；「测试」按钮会真调一次并告诉你是否识别出测试待办。

**Q：提醒没有提前响？**
背包 → 专注 → 提前提醒；调度器每 20 秒扫描一次，提前量分钟数会在到期前触发。

**Q：数据在哪里 / 怎么备份？**
全部在本地 SQLite：见上文数据目录，备份整个目录即可（含 `pokemon-choose-you.db`）。

**Q：想暂时隐藏桌宠？**
桌宠右键菜单选「隐藏桌宠」（或托盘菜单「显示/隐藏桌宠」、全局快捷键 Ctrl+Shift+D），图鉴机仍后台提醒（通知照常）。关闭主窗口同样是收到托盘而不是退出——想彻底退出走托盘菜单「退出」（背包 → 通用里也可改回「关闭即退出」）。
