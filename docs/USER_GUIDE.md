## 安装与首次启动

### 从安装包安装

- **macOS**：双击 `.dmg`，将应用拖入「应用程序」。首次打开若提示"无法验证开发者"，在「系统设置 → 隐私与安全性」点击「仍要打开」
- **Windows**：运行 NSIS 安装包（`.exe`），按向导完成安装
- **Linux**（实验性）：`.deb` / `.rpm` 用包管理器安装，或下载 `.AppImage` 加执行权限后直接运行（`chmod +x pokemon-knock_*.AppImage && ./pokemon-knock_*.AppImage`）。注意：桌宠窗口需 X11（Wayland 下置顶不可靠）；NVIDIA 显卡若白屏/黑块，启动前 `export WEBKIT_DISABLE_DMABUF_RENDERER=1`

### 首次启动

应用启动后会出现两个窗口：

- **图鉴机**（主面板）：任务管理、设置
- **桌宠**：常驻桌面的透明小窗口（透明置顶，不占任务栏）

建议第一件事：打开图鉴机 → 设置 → 通用 → 打开「开机自动启动」，以后登录系统桌宠自动出现。

> 数据全部存在本地（macOS: `~/Library/Application Support/com.joeca.pokemonknock/`，Windows: `%APPDATA%/com.joeca.pokemonknock/`，Linux: `~/.local/share/com.joeca.pokemonknock/`），卸载重装不丢任务。

## 核心概念（世界观）

**任务 = 野生宝可梦**。整个应用围绕一条捕捉链路：

```
遇见（新建） → 丢进草丛/加入路线 → ▶出发（派出宝可梦） → 捕获中（专注） → ✔已捕捉·登录图鉴
```

| 菜单 | 含义 | 类比 |
|---|---|---|
| **冒险** | 今天要完成的任务（进行中 + 今日到期） | 每日冒险 |
| **草丛** | 还没决定怎么处理的任务 | 野生宝可梦出没地 |
| **路线** | 按日期排期的未来任务 | 前进道路（Route） |
| **图鉴** | 已完成的任务 | 捕捉成就图鉴 |
| **收音机** | 飞书消息里识别出的待办建议 | 收听电波 |

每个任务分类绑定一只宝可梦（默认：工作=皮卡丘、学习=可达鸭、生活=妙蛙种子、健康=吉利蛋、社交=伊布、紧急=卡比兽），桌宠显示的精灵随当前任务的分类自动切换。

## 五分钟上手

1. **建一个任务**：图鉴机顶部输入「要捕捉哪只野生宝可梦？」，选分类、优先级、时间，开关拨到「丢进草丛」或「加入路线」，点 **＋ 捕捉**
2. **开始专注**：在冒险页点任务的 **▶ 出发**——桌宠的宝可梦换装上岗，对话框显示「皮卡丘正在捕捉：xxx」，番茄钟自动开始倒计时
3. **随时可见自己在干嘛**：桌宠常驻显示当前任务；想换就点精灵展开**快捷图鉴屏**，选中列表里的任务点「▶ 出发」，对话框会喊「就决定是你了！」
4. **完成**：点番茄钟上的 **✔**，任务变成「已捕捉」进入图鉴，今日进度条 +1
5. **等收音机送任务上门**：配置好飞书 + AI 后（见下文），飞书消息里的承诺和待办会自动变成建议，在收音机里逐条「◎ 捕捉 / ✕ 逃走」

## 桌宠详解

### 布局（初代战斗界面）

精灵在上、全宽对话框在下（右下角 ▼ 闪烁）、番茄钟药丸在底部。

### 操作

| 操作 | 效果 |
|---|---|
| **按住拖动** | 移动桌宠窗口（移动超过 4px 才算拖，不会误触） |
| **单击精灵** | 展开/收起**快捷图鉴屏**，精灵蹦跳 + 随机台词 |
| **双击精灵** | 打开图鉴机主面板 |
| 番茄钟 ⏸ / ▶ | 暂停 / 恢复当前任务计时 |
| 番茄钟 ✔ | 完成当前任务 |
| 番茄钟 ⇄ | 弹出切换目标列表 |

### 桌宠状态

- **工作中**：精灵跳跃动画，对话框显示「xx正在捕捉：任务名」
- **暂停**：精灵变灰
- **紧急提醒**：对话框抖动 + 红色系统通知「‼ 宝可梦来敲门」
- **普通提醒**：气泡换文案 + 系统通知，15 秒后自动恢复
- **番茄结束**：抖动提示 + （可选）系统通知；配置了短休息则自动进入 ☕ 蓝色倒计时，休息完提示「点 ▶ 开新一轮番茄」

## 图鉴机详解

### 任务条目（图鉴条目卡）

每张卡片包含：条目编号 `No.013`、分类精灵图、标题、属性徽章、优先级圆点（紧急=红闪）、截止/提醒时间、专注时长、来源。

进行中的任务有黄色描边 +「♪ 捕获中」角标；已完成的变 LCD 灰绿色、标题划线、精灵剪影化，可「↩ 撤销」。

### 捕捉进度条

冒险页右上角 `CAUGHT 5/8`——今日完成数/总数，一眼看到今天的战绩。

### 新建表单

第一行：标题输入；第二行：分类 → 优先级 → 日期时间 → 去向开关（丢进草丛/加入路线）→ **＋ 捕捉**。

日期时间选择器：点开是图鉴风日历（月份/星期跟随语言）+ 时:分 下拉，「清空」可取消时间。只拨时间没选日期时默认落在今天。

## 设置中心

设置分五个分区（上选单下内容，保存按钮吸底）：

| 分区 | 内容 |
|---|---|
| **🍅 专注** | 番茄钟开关、时长（15/25/45/60 分）、短休息（关/5/10 分）、番茄完成通知 |
| **🗂 分类** | 分类增删改；每行可给分类换宝可梦（6 只内置）；「放生」分类时其任务自动归入第一个分类 |
| **👀 显示** | **语言**（简体中文/繁體中文/English，即时切换）、日期格式、时间制式（带预览） |
| **📋 新任务默认值** | 默认优先级、默认去向（草丛/路线）——新建表单的初始值跟随这里 |
| **集成** | AI / 飞书 / Todoist 配置（见下文三节） |
| **⚙️ 通用** | 开机自启 |

另有：**🔔 提醒与通知**（通知总开关、提前提醒 0/5/15/30 分钟）在专注分区。

## 对接飞书（收音机）

让飞书消息里的待办自动变成图鉴机里的建议。**全程免费、无需公网服务器。**

### 第一步：创建飞书自建应用

1. 打开 [飞书开放平台](https://open.feishu.cn) → 创建企业自建应用（个人版飞书即可）
2. 记下 **App ID** 和 **App Secret**

### 第二步：开通权限

进入应用「权限管理」，开通：

- `im:message`（获取与发送单聊、群组消息）——用于读取机器人所在会话的历史消息

发布应用版本并让管理员（自己）通过审核。

### 第三步：拉机器人进群

把应用机器人添加到你希望监控的群聊/单聊（群设置 → 群机器人 → 添加自定义应用）。

### 第四步：图鉴机配置

设置 → 集成 → 飞书：填入 App ID / App Secret，打开「启用后台轮询」，选轮询间隔（默认 2 分钟），点「测试飞书连接」——提示"连接成功，机器人在 N 个会话中"即通。

### 使用

之后每轮轮询：拉取新消息 → AI 分类 → 含待办/承诺/时间的消息进入**收音机**（菜单上有红色计数）。你逐条确认：**◎ 捕捉**（进草丛）或 **✕ 逃走**。只有你确认过的才会成为任务，AI 不会自作主张。

> 断网自动退避重试（间隔翻倍，上限 8 倍），恢复后自动追平，日志可查。

## 对接 AI 接口

用于飞书消息的待办识别。支持任何 OpenAI 兼容接口：

| 服务 | Base URL | 模型示例 |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash`（免费额度） |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |

设置 → 集成 → AI 接口：填 Base URL（**到 `/v1` 为止**）、API Key、模型名，点「测试 AI 连接」——会真调一次接口并报告能否识别测试待办。

## 对接 Todoist

设置 → 集成 → Todoist：粘贴 API Token（Todoist 网页版 → Settings → Integrations → API token），点「立即同步」。

同步规则：

- **远端 → 本地**：Todoist 任务按 `external_id` 去重拉取
- **本地 → 远端**：草丛以外（已排期/进行中）的本地任务推送到 Todoist
- **完成联动**：本地标记完成的任务会自动关闭远端任务

> Todoist 免费版 API 完全够用；同步失败会返回具体原因，重试即可。

## 常见问题

**Q：桌宠点击没反应？**
按住拖动超过 4px 才算拖拽，原地点击才会触发交互；另外确认点的是精灵/对话框区域，番茄钟按钮和快捷屏内部不触发拖拽。

**Q：中文/emoji 显示成方块？**
WSLg 环境缺字体。下载 [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk) 和 Noto Color Emoji 放入 `~/.local/share/fonts`，执行 `fc-cache -f`。macOS / Windows 无此问题。

**Q：收不到系统通知？**
- macOS：系统设置 → 通知 → 宝可梦来敲门 → 允许
- Windows：设置 → 系统 → 通知 → 开启应用通知
- 应用内：设置 → 专注 → 「任务提醒通知」需开启

**Q：飞书拉不到消息？**
依次检查：① 机器人确实在群里；② `im:message` 权限已开通且版本已发布；③ 日志 `~/.local/share/com.joeca.pokemonknock/logs/`（macOS/Windows 路径见上）里有 `feishu poll failed` 具体原因；④「测试飞书连接」是否成功。

**Q：AI 分类结果不准？**
换模型（推荐带 chat 后缀的 newer 模型）；测试连接功能会直接告诉你模型是否识别出测试待办。

**Q：提醒没有提前响？**
设置 → 专注 → 提前提醒；调度器每 20 秒扫描一次，提前量分钟数会在到期前触发。

**Q：数据在哪里 / 怎么备份？**
全部在本地 SQLite：见上文数据目录，备份整个目录即可（含 `pokemon-knock.db`）。

**Q：想暂时隐藏桌宠？**
直接关闭桌宠窗口，图鉴机仍后台提醒（通知照常）；重新打开应用即可唤回。托盘常驻模式在路线图上。
