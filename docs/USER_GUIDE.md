## 安装与首次启动

### 从安装包安装

- **macOS**：双击 `.dmg`，将应用拖入「应用程序」。首次打开若提示"无法验证开发者"，在「系统设置 → 隐私与安全性」点击「仍要打开」
- **Windows**：运行 NSIS 安装包（`.exe`），按向导完成安装
- **Linux**（实验性）：`.deb` / `.rpm` 用包管理器安装，或下载 `.AppImage` 加执行权限后直接运行（`chmod +x pokemon-choose-you_*.AppImage && ./pokemon-choose-you_*.AppImage`）。注意：桌宠窗口需 X11（Wayland 下置顶不可靠）；NVIDIA 显卡若白屏/黑块，启动前 `export WEBKIT_DISABLE_DMABUF_RENDERER=1`

### 首次启动

应用启动后会出现两个窗口：

- **图鉴机**（主面板）：任务管理、设置
- **桌宠**：常驻桌面的透明小窗口（透明置顶，不占任务栏）

建议第一件事：打开图鉴机 → 设置 → 通用 → 打开「开机自动启动」，以后登录系统桌宠自动出现。

> 数据全部存在本地（macOS: `~/Library/Application Support/com.jotsai.pokemonchooseyou/`，Windows: `%APPDATA%/com.jotsai.pokemonchooseyou/`，Linux: `~/.local/share/com.jotsai.pokemonchooseyou/`），卸载重装不丢任务。
>
> **自动备份**：每天第一份快照存在数据目录的 `backups/` 下（`VACUUM INTO` 压缩产物），默认滚动保留 7 份，可在 设置 → 通用 → 数据备份 调整份数、立即备份或从任意一份恢复（恢复立即生效、无需重启，会覆盖当前全部数据；秘钥在系统钥匙串不受影响）。
>
> **导出 / 导入**：设置 → 通用 → 数据导出 / 导入。全量 JSON（可在别的机器整体导入，秘钥不出文件）、任务 CSV（带 BOM，Excel 直接打开）、今日日报 Markdown（已完成/路线上/今日跟进三段，勾选框语法，可直接并入 Obsidian 等知识库）；产物都在数据目录 `exports/` 下，可一键打开目录。

## 核心概念（世界观）

**任务 = 野生宝可梦**。整个应用围绕一条捕捉链路：

```
遇见（新建） → 丢进草丛/加入路线 → ▶出发（派出宝可梦） → 捕获中（专注） → ✔已捕捉·登录图鉴
```

| 菜单 | 含义 | 类比 |
|---|---|---|
| **冒险** | 今天要完成的任务（进行中 + 今日到期） | 每日冒险 |
| **草丛** | 还没决定怎么处理的任务 | 野生宝可梦出没地 |
| **路线** | 按日期排期的未来任务 | 前进道路（Route） |
| **图鉴** | 已完成的任务 | 捕捉成就图鉴 |
| **收音机** | 飞书消息里识别出的待办建议 | 收听电波 |

每个任务分类绑定一只宝可梦（默认：工作=皮卡丘、学习=可达鸭、生活=妙蛙种子、健康=吉利蛋、兴趣=伊布），桌宠显示的精灵随当前任务的分类自动切换。分类可在设置里换装成 **PokeAPI 全部 1025 只**中的任意一只（内置 6 只离线可用，其余首次展示时联网加载精灵图）；没有任务时桌宠展示**主宝可梦**（设置 → 分类，不设置则跟随第一个分类），每只宝可梦还能写**专属台词**（点击桌宠时随机冒出）。旧版本里的「社交」「紧急」分类升级后自动移除（其下任务并入第一个启用分类），如仍需要可在设置里手动重建。

## 五分钟上手

1. **建一个任务**：图鉴机顶部输入「要捕捉哪只野生宝可梦？」，选分类、优先级、时间，开关拨到「丢进草丛」或「加入路线」，点 **＋ 捕捉**
   - **偷懒写法（自然语言）**：直接输入「明天 5pm 交周报 #工作」——时间、分类、标签自动识别，输入框下方出现**高亮预览**（识别成什么一目了然），看着不对点 **✕ 取消识别** 按原文保存；设置 → 通用里可整体关闭。支持今天/明天/后天、（下）周X、X月X日、5pm、下午3点半等写法，`#名字` 只认已有的分类与标签，认不出的一律留在标题里不猜。
2. **开始专注**：在冒险页点任务的 **▶ 出发**——桌宠的宝可梦换装上岗，对话框显示「皮卡丘正在捕捉：xxx」，番茄钟自动开始倒计时
3. **随时可见自己在干嘛**：桌宠常驻显示当前任务；想换就点精灵展开**快捷图鉴屏**，选中列表里的任务点「▶ 出发」，对话框会喊「就决定是你了！」
4. **完成**：点番茄钟上的 **✔**，任务变成「已捕捉」进入图鉴，今日进度条 +1
5. **等收音机送任务上门**：配置好飞书 + AI 后（见下文），飞书消息里的承诺和待办会自动变成建议，在收音机里逐条「◎ 捕捉 / ✕ 逃走」

## 就近可操作提醒

「提醒 → 打开应用 → 找到任务 → 完成」的链路常在第二步就流失。现在提醒触发时，桌宠的提醒气泡下方**直接带两个动作按钮**：

- **✔ 完成**：就地标记完成，精灵立刻庆祝
- **⇨ 推迟 10 分钟**：回写提醒时间，到点再敲一次门

就近消化，完全不需要打开主面板。动作条停留 60 秒或直到操作完成。
## 逾期 fresh start（反羞耻）

逾期堆积成「羞耻墙」是弃用生产力应用的头号触发点。冒险页的逾期任务**默认不逐条堆显**：折叠成一行低调的「🎒 昨天有 N 只溜走了（点开看看）」，点开才展开；行内「全部归草丛」一键清掉逾期时间让它们回草丛重新安排——任务不删、不指责。

设置 → 显示 → 「逾期任务展示」三模式：**折叠为一行**（默认）/ **自动归草丛**（每天首次运行时自动清逾期未开始任务的截止时间）/ **原样显示**。

## 「先试 5 分钟」启动模式

卡在「启动」上时，最短 15 分钟的番茄钟也是门槛。桌宠番茄钟未运行时（暂停或还没开始）有一个 **🍦 按钮**：开启一场明示「不成也没关系」的 5 分钟超短专注——精灵会说「就试 5 分钟，不成也没关系！」。

5 分钟到了**不自动接休息**：气泡换成「感觉对了就 ▶ 继续，今天到此为止也完全 OK」，继续或收工都被肯定——零挫败的入场券与退出门票。

## 环境化倒计时（时间感知）

数字倒计时读不进脑子——专注时桌宠精灵外圈有一圈**随剩余时间渐变的色环**（绿 → 琥珀 → 红），不需要读数字也能感觉到时间在流逝；进入尾段（剩 5 分钟或不足两成）精灵会**蹦跳加速**表现焦急。

**长番茄钟保护**（45/60 分钟档）：过中点响一声、剩 5 分钟响两声轻提示音（音量克制），既维持时间感知也防止过度专注；设置 → 专注 → 「轻提示音」可关。

## 相对截止时间（时间盲友好）

注意力对「9月15日 14:00」无感、对「还有 5 小时」有反应——任务卡上的截止时间默认显示为**距现在的距离**并按临近程度变色：

- 已逾期 X 分钟 / 小时 / 天 —— 红色加粗
- X 分钟后（1 小时内）—— 红色
- X 小时后（今天稍后）/ 明天 15:00 / 后天 09:00 —— 琥珀
- 周X（一周内）—— 常规
- X 天后（更远）—— 灰色

鼠标悬停可看绝对时间；设置 → 显示 → 「相对截止时间」可关闭回绝对显示。

## 每周复盘（训练家复盘）

图鉴页右上角 **🧢 复盘** 打开四步向导：

1. **总览**：本周捕捉数 / 专注分钟 / 路线上 / 草丛里的任务量，按分类的捕捉条形图
2. **路线复盘**：逐站过一遍路线上（含进行中）的任务——保留 / ✔ 完成 / 归草丛（清截止时间）/ 🚪 逃走，就地处置
3. **草丛归位**：勾选不再想做的草丛任务批量放生，或全选一键清理
4. **收尾**：记录本周已复盘，显示本周总收服数

**提醒**：设置 → 通用 → 每周复盘提醒，可选提醒日（默认周一）；到点发系统通知，每周一次。主流任务应用（除 OmniFocus 外）没有内置回顾，带提醒的复盘是本应用的差异化能力。

## 桌宠详解

### 布局（初代战斗界面）

精灵在上、全宽对话框在下（右下角 ▼ 闪烁）、番茄钟药丸在底部。

### 操作

| 操作 | 效果 |
|---|---|
| **按住拖动** | 移动桌宠窗口（移动超过 4px 才算拖，不会误触） |
| **单击精灵** | 展开/收起**快捷图鉴屏**，精灵蹦跳 + 随机台词 |
| **双击精灵** | 打开图鉴机主面板 |
| **右键精灵** | 菜单：打开图鉴机 / 快捷图鉴屏 / 暂停当前任务 / 隐藏桌宠 |
| 番茄钟 ⏸ / ▶ | 暂停 / 恢复当前任务计时 |
| 番茄钟 ✔ | 完成当前任务 |
| 番茄钟 ⇄ | 弹出切换目标列表 |

### 桌宠状态

- **工作中**：精灵跳跃动画，对话框显示「xx正在捕捉：任务名」
- **暂停**：精灵变灰
- **紧急提醒**：对话框抖动 + 红色系统通知「‼ 训练家，快看快看！」
- **普通提醒**：气泡换文案 + 系统通知，15 秒后自动恢复
- **番茄结束**：抖动提示 + （可选）系统通知；配置了短休息则自动进入 ☕ 蓝色倒计时，休息完提示「点 ▶ 开新一轮番茄」

## 图鉴机详解

### 任务条目（图鉴条目卡）

每张卡片包含：条目编号 `No.013`、分类精灵图、标题、属性徽章、优先级圆点（紧急=红闪）、截止/提醒时间、专注时长、来源。

进行中的任务有黄色描边 +「♪ 捕获中」角标；已完成的变 LCD 灰绿色、标题划线、精灵剪影化，可「↩ 撤销」。

**右键任务卡**：出发/暂停、加入路线、编辑、完成、逃走、放生（删除）等动作都在右键菜单里，与卡片按钮一一对应；菜单底部还有「查看详情」和「复制标题」。输入框右键则是熟悉的剪切/复制/粘贴/全选。

### 捕捉进度条

冒险页右上角 `CAUGHT 5/8`——今日完成数/总数，一眼看到今天的战绩。

### 新建表单

第一行：标题输入；第二行：分类 → 优先级 → 日期时间 → 去向开关（丢进草丛/加入路线）→ **＋ 捕捉**。

日期时间选择器：点开是图鉴风日历（月份/星期跟随语言）+ 时:分 下拉，「清空」可取消时间。只拨时间没选日期时默认落在今天。

## 设置中心

设置分七个分区（上选单下内容，保存按钮吸底）：

| 分区 | 内容 |
|---|---|
| **🍅 专注** | 番茄钟开关、时长（15/25/45/60 分）、短休息（关/5/10 分）、番茄完成通知 |
| **🗂 分类** | **主宝可梦**（空闲桌宠展示）；**宝可梦台词**（每只可写专属语录）；分类增删改，每行可给分类换宝可梦（PokeAPI 全量 1025 只，按名称/编号/英文名搜索）；「放生」分类时其任务自动归入第一个分类 |
| **🏷 标签** | 标签增删改；AI 从聊天消息生成待办时会从这些标签里挑选合适的打上 |
| **👀 显示** | **语言**（简体中文/繁體中文/English，即时切换）、日期格式、时间制式（带预览） |
| **集成** | AI / 飞书 / Todoist 配置（见下文三节） |
| **🩺 诊断** | 集成健康面板 + 运行日志查看器 + 支持报告（见下节） |
| **⚙️ 通用** | 开机自启 |

另有：**🔔 提醒与通知**（通知总开关、提前提醒 0/5/15/30 分钟）在专注分区。

## 诊断中心

设置 → 诊断，一条页面看清三条外部链路（飞书电波 / AI Agent / Todoist）的运行状态：

- **集成健康**：每条链路展示三档状态（正常 / 降级重试中 / 故障）、上次成功时间、下次轮询时间、连续失败次数、最近错误；飞书还显示收音机里待确认建议的积压数。失败会自动指数退避重试，也可点「立即拉取 / 立即同步」手动触发。
- **运行日志**：按级别（全部 / INFO / WARN / ERROR）与来源关键词过滤，最新在上方，无需再去数据目录翻文件。
- **复制支持报告**：一键生成「版本 + 平台 + 健康快照 + 最近 200 条日志」并复制到剪贴板，密钥与令牌已自动脱敏，可直接贴进 issue。

## 对接飞书（收音机）

让飞书消息里的待办自动变成图鉴机里的建议。**全程免费、无需公网服务器。**

消息拉取走**官方 lark-cli**（[larksuite/cli](https://github.com/larksuite/cli)）：消息以**你的身份**拉取，私聊和群聊都能听见，**不需要把机器人拉进任何会话**；lark-cli 的自建应用与授权凭证都由它自己保管（**不进本应用数据库**），应用内无需填写任何飞书配置。

> WebSocket 实时事件：lark-cli 提供 lark-event 订阅能力，但常驻桌宠应用管理长连接生命周期（断线重连、休眠唤醒、多实例）复杂度尚高，当前版本按设置的间隔轮询；拉取已按命令抽象，后续可平滑接入。

### 第一步：安装 lark-cli

```bash
npm install -g @larksuite/cli
```

### 第二步：授权登录

设置 → 集成 → 飞书，点「**授权登录**」——应用会在系统终端里运行 lark-cli 的登录流程（首次会先 `lark-cli config init --new` 在浏览器里为你自动创建自建应用，再 `lark-cli auth login --domain im --recommend` 完成用户授权；之后只跑登录命令）。在终端里完成授权后回到设置页点「测试飞书连接」。系统没有可用终端模拟器时（如未装桌面终端的 WSL），错误提示会给出可手动粘贴的完整命令。

### 第三步：启用轮询

1. 打开「启用后台轮询」，选轮询间隔（默认 2 分钟）
2. 点「测试飞书连接」——提示"连接成功（lark-cli）：已授权「你的名字」，可见 N 个会话"即通

### 使用

之后每轮轮询以你的身份拉取新消息（**免打扰的会话整个跳过**——想屏蔽的噪音群/折叠群请顺手设为免打扰），按聊天语境分别处理：

- **你私聊发给机器人的消息**（与机器人/助手的单聊）——当作你给自己记的备忘/指令，交 AI 判定（机器人的回复只作上下文）
- **你发给自己的会话**——同样当作备忘，交 AI 判定
- **别人私聊发给你的消息**——交 AI 判定（你回复的消息只作上下文）
- **群聊里别人发的消息**——交 AI 判定（你自己的消息只作上下文）

AI 判定时会带上**同会话 30 分钟内的近期上下文**与消息来源（私聊/群聊/机器人、发送者姓名），帮助理解指代与时间。每条建议都会附**判定理由**与**置信档位**（高/中/低——低置信的建议值得多看一眼）。判定动作有四种：

| 动作 | 什么时候 | 去向 |
|---|---|---|
| **新待办** | 消息里出现新的任务/承诺/会议 | 收音机生成建议卡，**◎ 捕捉**（进草丛）或 **✕ 逃走** |
| **更新建议** | 消息是对现有待办的变更（改期、调整优先级、换标题、变更要求） | 收音机生成更新卡，列出要改的字段，**◎ 应用更新** 后打补丁到原待办 |
| **跟进记录** | 消息是现有待办的补充信息/进展/确认 | 自动记入该待办的跟进记录（可在编辑弹窗查看） |
| **无动作** | 闲聊、纯信息、重复提及 | 仅留档 |

逃走时可以顺手选一个**原因码**（已有类似待办 / 不是给我的任务 / 建议内容不对 / 闲聊噪音 / 已过期 / 其他）——这些反馈连同建议与判定模型一起存在本地，用来帮 AI 越判越准；不选直接逃走也完全可以。批量逃走可先用旁边的下拉统一选原因。

只有你确认过的才会创建/修改任务，AI 不会自作主张（跟进记录是追加信息，无破坏性，故自动记录）。

富文本消息会转成可读文本（@人还原成姓名、链接带地址、图片/文件/语音以 `[图片]` `[文件:名字]` 等占位）；纯媒体消息只作上下文，不送 AI。群成员姓名通过群成员接口解析并本地缓存。

> 断网自动退避重试（间隔翻倍，上限 8 倍），恢复后自动追平，日志可查。

## 配置 AI Agent CLI

用于飞书消息的待办识别与判重。改为调用本地 **AI agent 命令行工具**（无头模式），不再走 AI 接口：

| Agent | 命令 | 无头调用 | 历史记录参数 |
|---|---|---|---|
| Claude Code | `claude` | `-p {prompt}` | `--resume` |
| OpenCode | `opencode` | `run {prompt}` | （TUI 自带会话列表） |
| Kiro CLI | `kiro` | `-p {prompt}` | `--resume` |
| 其他 | 任意 | 自定义 | 自定义 |

**SSH 远程执行**：agent CLI 不在本机时，在 agent 配置里勾选「SSH 远程执行」并填目标（`user@host`，可指定端口与私钥路径）。实际执行的命令是 `ssh -o BatchMode=yes -o ConnectTimeout=10 [-i 密钥] [-p 端口] user@host -- <command> <args...>`：

- 提示词一律走**标准输入**转发（`{prompt}` 占位符参数自动剔除，如 `claude -p {prompt}` 远程执行为 `claude -p` + stdin），避免 ssh 拼接 argv 后被远端 shell 打碎
- 需要先配好**公钥免密登录**（BatchMode 不允许交互输密码）；连接超时 10 秒，整次调用仍受该 agent 的超时设置约束
- 「历史记录」入口同样经 ssh 转发，`claude --resume` 等交互界面照常可用
- 环境变量 `PK_SSH_BIN` 可覆盖 ssh 客户端程序名（默认 `ssh`）
- **远程 agent 使用 pk 工具（一键配置）**：数据在本机，远程放一个经**反向隧道**回连的透传 shim——应用的每条 ssh 连接把远程的 `127.0.0.1:隧道端口` 转回本机 sshd，远程 agent 经 shim 回本机执行 pk；隧道随调用建立、随调用拆除，**本机不开放任何入站端口**。用户只需两步：
  1. **本机开启 sshd**（隧道终点，仅本机回环可达即可，防火墙无需放行）：macOS 系统设置 → 通用 → 共享 → 远程登录；Windows 安装并启动「OpenSSH SSH 服务器」可选功能；Linux `sudo systemctl enable --now sshd`
  2. agent 的 SSH 配置区点 **「一键配置远程 pk」**（隧道端口默认 10022）

  一键配置自动完成（全程幂等，可重复点击）：生成/复用专用密钥 → 公钥装配本机 `authorized_keys` → 私钥推到远程 `~/.ssh/pk_shim` → 预信任 `[127.0.0.1]:端口` 的主机指纹（shim 走 BatchMode，首次连接的交互确认必须预先写入 known_hosts 才不会失败）→ 安装 shim（内嵌本机 pk 绝对路径）到远程 `~/.local/bin/pk` 并保障登录 shell 的 PATH → 把隧道端口写回 agent 配置 → 开一条真实隧道端到端验证（远程 `pk --version` 应返回本机版本）。失败会指明停在哪一步与修法；成功后可再点「测试」跑工具探针。手工等价命令：`pk remote shim --host <本机用户名>@127.0.0.1 --port 10022`；排障可跑 `pk doctor --ssh <远程>`。

  > 同一远程机器配多个 agent 时请保持相同的隧道端口（shim 按端口回连）。

设置 → 集成 → AI Agent CLI：

1. 选预设 → 点「＋ 添加 Agent」（也可自定义命令与参数）；
2. 可配置多个：用单选「用于收音机分类」指定当前生效的 agent，其余作为备用；
3. 点「测试」会真调一次 agent 并报告能否识别测试待办；
4. 点「历史记录 ↗」会在新终端中打开该 agent 的会话历史（历史由 agent 工具自己保存）。

要点：

- **{prompt} 占位符**：附加参数中的 `{prompt}` 会被替换为完整提示词；不写占位符则提示词经标准输入传入（适合长提示词）。
- **工作目录**：agent 及其工具（读写文件、git 等）的相对路径基准，支持 `~` 前缀；留空为应用专属工作区 `~/.choose-you`（不存在会自动创建，与数据库所在的应用数据目录互不混放）。应用启动方式不同、GUI 进程的默认目录不可控（Dock/Finder 启动时是 `/`），所以总会显式指定，不会「随机」落盘。SSH 远程模式下填的是**远程机器上的路径**，调用与「历史记录」终端会话都会先切到该目录；远程留空则落在远端登录目录（远端 `$HOME`）。
- **超时**：agent 启动 + 推理比直连 API 慢，默认 120 秒，可按需调大。
- Windows 下 npm 全局命令（`claude.cmd` 等）会自动经 `cmd /C` 回退启动，无需绝对路径。

**结果回收模式**（每个 agent 独立选择）：

- **文本解析（默认）**：应用解析 agent 输出中的 JSON 建议，任何能输出 JSON 的命令都兼容——原有行为。
- **工具调用（经 pk 落库）**：agent 先跑 `pk context` 拿判重上下文，再用 `pk suggest batch` 把整批判定一次性写回数据库，应用直接回读，不再解析输出文本（更可靠，且判定结果带强校验）。本机调用时应用会把随附 `pk` 所在目录自动注入 agent 子进程的 PATH，无需手动配置；远程 agent 则用下文的「一键配置远程 pk」。要求 agent 无头模式下允许执行 pk 命令：
  - Claude Code：附加参数改为 `-p {prompt} --allowedTools Bash(pk:*)`（`:*` 为前缀匹配语法；参数按空白切分，**不要加引号**——引号会变成值的一部分）
  - OpenCode / Kiro：在其权限配置中允许执行 `pk` 命令
  - 工具循环比单轮输出慢，建议把超时调大到 300 秒左右；「测试」按钮在该模式下会真跑一次 `pk context`，一次验证命令可用、工具白名单、PATH 与数据库整条链路

## pk 命令行（供 AI agent 与终端使用）

应用随包分发 `pk` CLI，全部输出 JSON，可直接给 AI agent 工具（claude code / opencode / kiro…）当工具用，也可自己在终端操作：

```bash
pk task list [open|done|today|all]   # 任务列表（默认 open）
pk task get 3                        # 任务详情（含跟进记录）
pk task search 关键词                 # 搜标题/备注/跟进/标签
pk task create --title "交周报" --due "2026-09-13T18:00" --tags 重要
pk task update 3 --priority high --due ""   # 空串清空截止时间
pk task done 3 && pk task start 5    # 完成 / 开始（全局唯一进行中）
pk note add 3 对方确认周五交付 --source ai
pk context                           # 当前时间 + 未完成待办 + 分类 + 标签（AI 判重上下文）
pk task create --title 交周报 --dry-run     # 只校验回显不落库（task update/delete 同）
pk suggest todo --message <消息id> --title 交周报 --due 2026-09-13T18:00  # 提交 AI 判定建议（写建议列待用户确认）
pk suggest batch --agent claude-code < suggestions.json                  # 批量提交（stdin 传 {"results":[...]}，整批校验）
pk remote shim --host <本机用户名>@127.0.0.1 --port 10022 > pk    # 手工生成远程透传脚本（应用内有「一键配置远程 pk」）
pk doctor                            # 环境自检：数据库/schema/技能安装，每项带修复建议（--ssh <host> 加测远程 pk）
pk help --json                       # 机器可读的命令目录（供 agent 编程化发现）
pk help                              # 完整命令说明
```

- **技能一键分发**：`pk skill install claude-code` 把 pk 使用技能装进 agent 的技能目录（claude-code → `~/.claude/skills/`，opencode → `~/.config/opencode/skill/`），含主文件 SKILL.md 与 references/ 引用文件（完整参数表、无头分类工作流），带版本标记、跨版本重装会提示更新；其他 agent 用 `--dir <目录>` 指定落点，或 `pk skill show` 打印全部内容自行粘贴
- **agent 友好性**：`--dry-run`（task create/update/delete 只校验回显不落库）、`task list --limit`（默认 50 条，`truncated` 提示用 search 收窄）、`help --json`（机器可读命令目录）、`doctor` 环境自检——检查数据库存在性、schema 版本、完整性、WAL 并发、context 读链路与技能安装版本，每项 ok/warn/fail 并附 `fix` 修复建议（有 fail 退出码 1）；远程部署排障加 `pk doctor --ssh <user@host>`，端到端验证 ssh 免密 → shim 在 PATH → 回连本机整条链
- **会话回链与成本记录**：agent 代办后 `pk session log --task 3 --agent claude-code --session <id> --cost 0.12 --duration-ms 61000` 落一条会话；任务编辑弹窗的「Agent 执行」区展示每次的时长 / 成本 / 退出码（含收音机分类调用），有会话 id 的可一键在终端回放转录（`claude --resume <id>`）
- 与桌面应用共用同一个 SQLite 库（WAL 并发安全），操作同样写入审计日志；
- 环境变量 `PK_DB` 可指定独立数据库路径（`pk init-db` 可引导空库）；
- 安装位置：应用安装目录（与主程序同级），加入 PATH 后即可全局使用。

## 对接 Todoist

设置 → 集成 → Todoist：粘贴 API Token（Todoist 网页版 → Settings → Integrations → API token），点「立即同步」。

同步规则：

- **远端 → 本地**：Todoist 任务按 `external_id` 去重拉取
- **本地 → 远端**：草丛以外（已排期/进行中）的本地任务推送到 Todoist
- **完成联动**：本地标记完成的任务会自动关闭远端任务

> Todoist 免费版 API 完全够用；同步失败会返回具体原因，重试即可。

## 常见问题

**Q：桌宠点击没反应？**
按住拖动超过 4px 才算拖拽，原地点击才会触发交互；另外确认点的是精灵/对话框区域，番茄钟按钮和快捷屏内部不触发拖拽。

**Q：中文/emoji 显示成方块？**
WSLg 环境缺字体。下载 [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk) 和 Noto Color Emoji 放入 `~/.local/share/fonts`，执行 `fc-cache -f`。macOS / Windows 无此问题。

**Q：收不到系统通知？**
- macOS：系统设置 → 通知 → 就决定是你了 → 允许
- Windows：设置 → 系统 → 通知 → 开启应用通知
- 应用内：设置 → 专注 → 「任务提醒通知」需开启

**Q：飞书拉不到消息？**
依次检查：① 终端里 `lark-cli auth status` 显示已登录（未登录时在设置页点「授权登录」重跑一遍）；② 终端里 `lark-cli config show` 正常（报 not_configured 就先 `lark-cli config init --new`）；③ 日志 `~/.local/share/com.jotsai.pokemonchooseyou/logs/`（macOS/Windows 路径见上）里有 `feishu poll failed` 具体原因；④「测试飞书连接」是否成功。

**Q：lark-cli 登录过期了怎么办？**
点一次「授权登录」（或在终端跑 `lark-cli auth login --domain im`）重新登录即可；凭证由 lark-cli 自管，应用无需其他操作。

**Q：AI 分类结果不准？**
换一个能力更强的 agent / 模型（agent CLI 内自行配置），或在 agent 中调整模型档位；「测试」按钮会真调一次并告诉你是否识别出测试待办。

**Q：提醒没有提前响？**
设置 → 专注 → 提前提醒；调度器每 20 秒扫描一次，提前量分钟数会在到期前触发。

**Q：数据在哪里 / 怎么备份？**
全部在本地 SQLite：见上文数据目录，备份整个目录即可（含 `pokemon-choose-you.db`）。

**Q：想暂时隐藏桌宠？**
桌宠右键菜单选「隐藏桌宠」（或托盘菜单「显示/隐藏桌宠」、全局快捷键 Ctrl+Shift+D），图鉴机仍后台提醒（通知照常）。关闭主窗口同样是收到托盘而不是退出——想彻底退出走托盘菜单「退出」（设置 → 通用里也可改回「关闭即退出」）。
