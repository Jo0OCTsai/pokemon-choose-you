# 《宝可梦来敲门》设计系统 — 图鉴复古风 (Pokédex Retro)

> 关键词：宝可梦图鉴 / 初代游戏机 / 粗描边漫画 / LCD 绿屏 / 硬阴影 / 低密度大目标
> 原则：像一台"任务图鉴机"——每条待办是一条图鉴条目，抓到（完成）一条就点亮一条。

## 1. 色彩 Tokens

### 机身色（结构）
| Token | 色值 | 用途 |
|---|---|---|
| `--dex-red` | `#EE1515` | 图鉴机主色：侧板、主按钮、头部条 |
| `--dex-red-dark` | `#B01010` | 红色按压态/渐变下沿 |
| `--dex-body` | `#F5F0DC` | 机身米白：内容区背景 |
| `--dex-navy` | `#1A1B25` | 所有描边、正文标题（描边统一 3px） |
| `--poke-yellow` | `#FFCB05` | 强调按钮、当前选中、高亮 |

### 屏幕色（信息区）

## 2. 字体

- **标题/数字/Logo**：`"Press Start 2P"`（像素）——只用于英文、数字、时间
- **中文正文**：`"Zpix"/"Fusion Pixel"`（中文像素，打包内置）；降级 `"Noto Sans SC"` 900
- 层级：页面标题 18px 像素 / 卡片标题 16px 700 / 正文 14px / 辅助 12px
- LCD 屏内：等宽像素字，深绿 `--lcd-text`

## 3. 形状与质感

- **描边**：全部元素 `3px solid var(--dex-navy)`，圆角 `8px`（按钮）/ `12px`（卡片）/ `4px`（徽章）
- **硬阴影**：`4px 4px 0 var(--dex-navy)`，禁止模糊阴影；按下时位移 `translate(2px,2px)` + 阴影减半（物理按键感）
- **扫描线**：LCD 屏叠加 `repeating-linear-gradient(0deg, rgba(0,0,0,.06) 0 2px, transparent 2px 4px)`
- **LED 指示灯**：8px 圆 + 内高光；红色=紧急待处理，绿色=一切正常，呼吸动画
- **精灵图**：`image-rendering: pixelated`，永远不模糊

## 4. 组件规范

### 4.1 任务卡 = 图鉴条目
```
┌────────────────────────────────────────┐
│ [精灵图] No.003  给老板发周报       [电] │  ← 条目编号 + 标题 + 属性徽章
│           截止 09-13 18:00 · ★专注42分  │
│                          [▶开始] [✔] [📅]│  ← 大按钮 ≥ 36px
└────────────────────────────────────────┘
```
- 进行中的条目：黄色边框 + 「♪ 捕获中」角标 + 精灵跳跃动画
- 完成的条目：整卡变 LCD 灰绿色，标题加删除线，精灵剪影化

### 4.2 主面板 = 图鉴机
- 左侧 200px 红色"机脊"：顶部大灯（状态 LED）→ 精灵球 Logo → 纵向菜单（▶ 光标指示当前页）→ 底部小提示
- 内容区米白，顶部一行大按钮筛选（今日/收件箱/已排期/图鉴(已完成)）
- IM 建议页：条目卡 LCD 屏样式（消息原文在屏内滚动），下方两个大按钮「捕捉 / 逃走」

### 4.3 桌宠窗口（初代战斗布局）
- 精灵在上（居中，工作中跳跃/暂停变灰）+ 分类小标签
- **全宽对话框在下**：白底 + 3px 外框 + 2px 内框双线结构，右下角红色 ▼ 闪烁（初代"继续"箭头）
- 番茄钟药丸：像素数字，休息态变蓝色 ☕ 前缀
- **点击精灵 → 展开"快捷图鉴屏"**（红色翻盖机身 + LCD 绿屏）：
  - 屏内：今日待办列表（▶ 光标选中，进行中带 ♪）
  - 屏底三个物理按钮（出发/暂停/收起）
- 紧急提醒：对话框抖动 + 「‼」；窗口展开时自动调高、收起恢复

### 4.5 表单组件（全部自绘，不依赖原生控件）
- **DexSelect**：白底描边按钮 + ▼ + 弹出列表（▶ 光标选中态、黄色高亮悬停、z-index 60 不受滚动容器裁剪）
- **DexToggle**：初代 Options 的 ON/OFF 开关；支持自定义状态文案（如 丢进草丛/加入路线）
- **DexDateTime**：图鉴风日历（月份/星期经 Intl 跟随语言，周一开头）+ 时:分下拉 + 清空
- 原生控件仅保留文本输入框；所有控件统一 38px 高

### 4.4 按钮尺寸（低密度大目标）
- 主操作按钮：高 ≥ 40px，图标+文字
- 最小点击目标：40×40px（ADHD 友好，避免误触挫败）
- 间距：卡片间 12px，区内 16px，留白优先

## 5. 动效

| 动效 | 参数 | 场景 |
|---|---|---|
| 精灵跳跃 | `translateY(-6px)` 1.6s 循环 | 进行中任务 |
| 紧急抖动 | `translateX(±3px)` 0.4s ×3 | 紧急提醒 |
| LED 呼吸 | opacity .4→1 2s | 常驻状态灯 |
| 按键按压 | `translate(2px,2px)` + 阴影 4→2px 80ms | 所有按钮 |
| 捕捉成功 | 精灵球旋转 + 卡片打勾闪黄 | 完成任务 |

## 6. 布局栅格

- 主面板：左侧机脊 200px + 内容自适应，内容区单列任务卡（不做多栏，保持低密度）
- 设置卡片：严格两栏网格——132px 固定标签列 + 控件列（初代 Options 界面的对齐方式）
- 新建表单：标题输入独占一行，其余控件第二行
- 每屏最多展示 5~6 张条目卡，超出滚动；滚动条样式化为像素粗条
