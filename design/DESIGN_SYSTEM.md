# 《就决定是你了》设计系统 — 图鉴复古风

> 关键词：宝可梦图鉴 / 初代游戏机 / 粗描边漫画 / LCD 绿屏 / 硬阴影 / 低密度大目标
> 原则：像一台「任务图鉴机」——每条待办是一条图鉴条目，抓到（完成）一条就点亮一条。
> 与 `src/dex.css` 当前实现一一对应。配套设计稿：`dex-demo.html`（图鉴机·令牌与组件）· `pet-interaction-demo.html`（桌宠动画，可交互）。

## 0. 设计原则（七条）

1. **像素是皮肤，不是氛围引擎**——风格只出现在展示层，信息阅读层永远清晰优先（混合排版）。
2. **分档纪律**——描边/阴影/圆角/时长/缓动各有档位与名字，禁止档外取值。
3. **低密度大目标**——主操作 ≥40px，控件 38px，行内密集小动作走 mini 档 32px（`.btn.mini`，全站唯一小按钮档）；命中区不足处用 padding 补偿。
4. **动效即信息**——循环动画只传达状态；生命感微动作是受调度的离散事件（§7）。
5. **对比度是硬约束**——信息文字 ≥4.5:1；彩色小图形靠 navy 描边兜底 3:1。
6. **减弱动效双通道**——系统偏好与应用内开关同时生效，动画即时完成、语义不丢。
7. **本地优先**——字体本地打包（fontsource + @vp-tw 子集包），不依赖网络。

## 2. 字体三级（混合排版：像素管展示，清晰字管阅读）

| 层 | 类 | 字体 | 用途 | 尺寸（点阵倍数纪律） |
|---|---|---|---|---|
| 像素英文 | `.px` | Press Start 2P（`@fontsource` 本地打包） | 编号、时间、LCD 英文、Logo | **只用 8/16/24px** |
| 中文展示 | `.px-cn` | Fusion Pixel 12px 比例版（`@vp-tw/cjk-web-fonts-fusion-pixel-font`，78 个 unicode 子集本地打包） | 页面标题等展示位 | **只用 12/24px** |
| 正文中日韩 | — | Noto Sans CJK（系统栈） | 所有正文/备注/消息全文 | 12/13/14/16/18px |

落地：`main.ts` / `pet-main.ts` 顶部 import 两包 CSS；**入口 HTML 不再引 Google Fonts，CSP 不放行字体域**。
⚠️ `@fontsource/fusion-pixel-*-sc` 只含 latin 子集，中文必须用 `@vp-tw/cjk-web-fonts-fusion-pixel-font`。

## 3. 形状与质感（四档 + 胶囊）

| 档位 | 描边 | 阴影 | 圆角 | 用途 |
|---|---|---|---|---|
| 机壳级 | 4px | 8px 8px 0 | 16px | 主窗口外框、机脊右缘、抽屉左缘（左圆角 16）、快捷屏 |
| 卡片级 | 3px | 4px 4px 0 | 12px | 任务卡、设置卡、居中弹窗/向导 |
| 控件级 | 3px | 3px 3px 0 | 8px | 按钮、输入、下拉、stab、全部弹层（下拉/日历/菜单/浮层） |
| 小件级 | 2px | 2px 2px 0 | 4px | 徽章、chip、kbd、小图标钮、菜单项/列表行 |
| 胶囊 | — | — | 999px | 标签胶囊（tag-chip / sug-tag），描边走小件级 2px |

- 按下态：位移 = 阴影一半（4→2、3→2、2→1），`--t-tap` 80ms；所有带按压态的控件必须带 `--t-tap` 过渡。
- **红线：任何地方禁止 blur 阴影、禁止渐变阴影。**
- 扫描线：LCD 叠加 `repeating-linear-gradient(0deg, rgba(0,0,0,.05) 0 2px, transparent 2px 4px)`。
- LED：10px 圆 + 2px 描边，`--ok-bright` 呼吸（2s）/ `--dex-red` 闪烁（≤3Hz）；精灵图 `image-rendering: pixelated`。

## 4. 组件规范

### 4.1 任务卡 = 图鉴条目（四态）
- 普通：白卡 3px/12px/4px；`No.xxx`（.px 8px）+ 精灵 52px + 标题 16px/800 + 辅助行 12.5px `--ink-soft`。
- 进行中：3px 黄 outline + 「♪ 捕获中」角标 + `pk-hop` 跳跃。
- 已捕捉：LCD 化（`--lcd` 底 + `--lcd-dark` 内阴影）+ 删除线 + 灰度精灵。
- 已逃走：`#F3EFE6` 底淡出 + `#B9B09A` 阴影——中性呈现，不催清零。

### 4.2 主面板 = 图鉴机
- 左 200px 红机脊：大灯（22px，>6 今日任务转常亮深红——反焦虑）→ 副灯 → `POKé-DEX`（.px 8px）→ 纵向菜单六项（冒险/路线/草丛/图鉴/收音机/设置，▶ 光标 + 黄底 active + `aria-current`）→ 底部小贴士。
- 内容区标题 `.px-cn` 24px；冒险页附日期（.px）与 `CAUGHT x/y` 进度条。
- z-index 层级：下拉 60 / 右键菜单 95 / 抽屉 70 / 弹窗 80 / 向导 90 / toast 100；遮罩 `rgba(28,34,68,.42)`。

### 4.3 收音机 = 两栏分诊
- 列表栏与详情栏约 **3:2 分栏**（列表栏最小 360px，随窗口伸缩）+ 频道聚合 + 批量条 + 详情栏（LCD 全文 + AI 建议盒三态 + 操作条）。
- 键盘流 ↑↓/J/K/C/X/F/Esc；kbd chip = .px 8px + 2px 描边（底边 3px 键帽感）。
- 乐观 UI + 右下角 5 秒撤销 toast（不弹窗不抢焦点）。

### 4.4 设置中心与诊断
- 七分区「初代菜单」stab（▶ 光标 + 黄底 active）+ 920px 限宽 + 底部状态栏。
- **设置行 = `SettingRow` 组件**：左侧「标题 + 说明」两行堆叠，右侧控件贴卡片右缘垂直居中（Windows 11 / macOS 系统设置模式）。
- **说明文字四层归属**：
  1. **标签只写名字**——一行以内（中文 ≤10 字），解释一律移出标签，禁止括号长注释。
  2. **行内说明 desc**——放在它解释的那行的标题正下方：12px `--ink-soft`、一句话（至多两行）；与控件同框，永不悬空夹在行与行之间。
  3. **区块副标题 sub**——交代整张卡的功能背景（这是干嘛的、上手前置条件），放卡片标题正下方。
  4. **卡片脚注 foot**——后果警告（恢复会覆盖数据）、边界行为（放生分类后任务去向）、平台限制等收尾型信息，统一沉到卡片底部（虚线分隔）。
  5. **写不下的下沉，不硬塞**——操作教程与实现细节移入动作上下文（按钮 title / 出错提示 / 用户指南）；平台限定的信息只在对应平台渲染；能示例的不解释（日期格式给预览行，勿扰时段给跨零点例子）。
- 诊断：健康三色点（`--ok`/`--warn`/`--dex-red` 闪烁）+ 状态 chip + LCD 日志屏（`--log-*` 着色）。

### 4.5 表单组件（自绘）
DexSelect / DexToggle / DexDateTime / PokemonPicker / DexContextMenu（role=menu），控件统一 38px 高，原生控件仅保留文本输入。

## 5. 桌宠（详案见 `PET_INTERACTION_DESIGN.md`，要点）

- **布局**：精灵在上（104px，命中区固定）+ 全宽对话框（双线框，右下 ▼）+ 番茄药丸 + 快捷图鉴屏（300×330↔590）。
- **静景四元素**：精灵 / 色环（时间盲友好，全程被动显示）/ 一句话对话框 / 药丸 2 钮 + 上下文（运行 ⏸✔；暂停 ▶🍦✔；⇄ 在右键菜单）。
- **交互语义**：单击=快捷屏（展开前一跳回应）、双击=图鉴机、右键=菜单、**按住 600ms=撸宠**（纯情绪，不打开面板）、拖拽=悬挂物理（小碎步 + 松手挤压回弹）。
- **状态机**：idle / working / paused / urgent / **asleep**（无任务 + 窗口 5 分钟无交互 → zzz 呼吸；任意交互揉眼醒来）。
- **捕捉演出**（≤1.5s，点击可跳过）：蹲（预备 120ms）→ 精灵球抛物线（300ms）→ 落地挤压 + **三摇**（600ms，±14°）→ 星星爆开 + 气泡台词；里程碑（累计 10/50/100/…）双排星星，收工（今日清零）加一跳。
- **问候**：每天首次出现按时段说一次（早/午/晚/深夜四档 + 主宝可梦名），只此一次。

## 6. 动效

**令牌**（`dex.css`）：时长 `--t-tap 80ms / --t-pop 150ms / --t-act 300ms / --t-scene 600ms`；缓动 `--e-pop`（过冲回弹）/`--e-snap`（快落轻冲）/`--e-sway`（摇摆往返）/`--e-sleep`（呼吸）——**禁用匀速与线性**（演出位移除外，如球 X 轴）。
**可爱三律**：落地必挤压 · 过冲必回弹 · 动作带预备帧（`pk-hop`/`pk-petted` 已内置）。

| 动效 | 参数 | 场景 |
|---|---|---|
| 精灵跳跃 `pk-hop` | 预备蹲→-7px→落地挤压，1.6s/3s 循环 | working / idle |
| 焦急加速 | 0.8s / 0.6s | 番茄尾段 |
| 紧急抖动 `pk-shake` | ±4px ×3 | 紧急提醒 |
| 生命微动作 | 眨眼 240ms / 左右看 1s / 翻面 1.2s / 哈欠 900ms | idle 随机 4~9s；working 只眨眼且 7~13s |
| 睡觉呼吸 | ±2%，3.2s | asleep |
| 捕捉演出 | §5 | 完成任务 |
| 按压位移 | 阴影减半，`--t-tap` | 所有按钮 |
| ▼ 闪烁 | 新事件闪 3 次后停（默认静态） | 对话框 |

**注意力红线**：同屏闪烁 ≤1；演出 ≤1.5s 且可跳过；永不主动索要注意力（一切演出是用户动作/设定事件的回应）；激励只有正反馈（无连击惩罚、无失望表情）。

## 7. 布局栅格

- 主面板：机脊 200px + 内容自适应；任务卡单列低密度，每屏 5~6 张。
- 间距走 4px 基准网格；设置行左文右控件（`SettingRow`，说明文字四层归属见 §4.4）；滚动条像素化（navy 粗条）。

## 8. 无障碍底线

- 全局焦点：`:focus-visible { outline: 3px solid var(--poke-yellow); outline-offset: 2px }`。
- 信息文字只用 `--ink`/`--ink-soft`；徽章浅底深字（§1）；红字白钮用 `--danger`。
- 闪烁 ≤3Hz、同屏 ≤1、时长有限；减动效双通道全关（含生命感调度器与演出）。
- aria：导航 `aria-current`、开关 `aria-pressed`、菜单 `role=menu`、图标钮 title/aria-label。
