# 《就决定是你了》文案准则 — 三视角体系

> 面向所有 UI / 通知 / CLI / 文档文案。动笔前先问一句：**这句话是谁在说、说给谁听**。
> 配套设计规范见 [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)（视觉），本文只管文字。

## 三视角

| 视角 | 谁在说话 | 出现场景 | 语气 | 例 |
|---|---|---|---|---|
| **训练家** | 用户（第一人称的世界） | 主窗口 tab 名、按钮、统计、复盘向导、日报 | 行动号召、简短有力 | 「▶ 出发」「◎ 捕捉」「本周共收服 N 只宝可梦！」 |
| **宝可梦** | 桌宠 / 提醒 | 桌宠气泡、系统通知标题与正文 | 陪伴、撒娇、鼓励；**永远不指责** | 「{p}正在捕捉：{t}」「🐾 训练家，别忘了」 |
| **图鉴机** | 设备拟人 | 加载、检索、诊断、更新（固件）、错误 | 复古电子设备，简短克制 | 「图鉴机遇到了点状况：{技术原文}」「图鉴机固件」 |

## 判定规则

- **产品名是训练家的台词**：「就决定是你了」= 选定目标、掷出精灵球那句话（开始任务瞬间桌宠喊出，`pet.gotcha`）。桌宠自己说话时不拿产品名自称。
- **任务相关文案说具体的宝可梦名**：与某个任务绑定的气泡/提醒/通知（`pet.remindUrgent` / `pet.pomoDone` 等）用该任务分类关联的宝可梦名（`{p}`）。两类例外保持泛称「宝可梦」：捕捉语境的固定文案（「要捕捉哪只野生宝可梦？」——「野生」是世界观修辞，不点名）；跨任务的聚合文案（图鉴统计、复盘、空态）。
- **主宝可梦只换精灵图**：空闲桌宠展示主宝可梦的图，但气泡、名牌等文案不出现它的名字。
- **每宝可梦可自定义台词**：设置里为单只宝可梦写的专属台词只出现在撸宠语录位（`randomQuote`），不覆盖系统功能文案；未写时回默认语录池。
- **「敲门」保留为功能语义**：紧急提醒时桌宠的敲门动画（宝可梦来敲你的窗）。它不是产品名，也不进正式文案，只在描述该功能时使用。
- **装饰性英文不入 i18n**：POKé-DEX / CAUGHT / ADVENTURE / ON-OFF 属复古 LCD 设计语言，保持原样、不随语言切换。
- **错误文案两层结构**：图鉴机前缀（世界观）+ 技术原文（排障信息原样保留，绝不吞掉）。
- **反羞耻原则**：逾期 =「溜走了 / 溜回草丛」，取消 =「逃走」，全文案不出现「失败 / 落后 / 拖延」式字眼；逾期相关通知一律温和语气（「想好了再去看，不急」）。

## 词汇表（动作映射）

| 产品动作 | 世界观词 | 不要用 |
|---|---|---|
| 创建 / 收下待办 | 捕捉 | 添加、新建 |
| 开始任务 | 出发 | 开始、播放 |
| 完成任务 | 捕捉到了 / 收服 | 打勾、完成（按钮可保留「完成」） |
| 取消任务 | 逃走 | 废弃、丢弃 |
| 删除任务 | 放生 | 删除（UI 可括注「放生（删除）」） |
| 逾期 | 溜走 / 溜回草丛 | 过期、失败 |
| 每周回顾 | 训练家复盘 | 总结、回顾 |
| 收件箱 | 草丛 | inbox |
| 日程 | 路线 | 日历 |
| 已完成列表 | 图鉴 | 归档 |
| 消息集成 | 收音机 / 电波 | 通知中心 |

## 用词统一

- **「训练家」**，不是「训练师」（简 / 繁 / 英统一为 Trainer）。
- 标点：中文语境用全角括号「（皮卡丘）」，英文用半角 `(Pikachu)`。
- emoji 前缀语义固定：`‼` 紧急 · `🐾` 桌宠 / 提醒 · `🍅` 番茄钟 · `🧢` 复盘 · `📙` 图鉴统计 · `✕` 放行 / 逃走 · `◎` 捕捉确认。

## 三语同步

- `src/i18n/{zh-Hans,zh-Hant,en}.ts` 三文件 key 结构必须一致；新增 key 三语同步（反例：`review.overdue` 曾三语齐缺，线上渲染出 key 本身）。
- 后端硬编码文案（scheduler 三语通知、导出日报、支持报告、pk CLI 帮助）与前端 i18n **同批修改**，否则通知与界面口吻脱节。
- e2e mock（`e2e/tauri-mock.ts`）与测试断言（scheduler / pk / App.spec）随文案一起改。
- 集成与诊断类设置（AI Agent / 飞书 / Todoist / SSH）保持工具语气，**不做世界观化**——那里用户要的是精确信息。
