按钮三档（目标）档1

主行动 = 黄按钮（墨线 + 硬阴影 + 按压位移 80ms）；次行动/表单控件 = 宿主档不动；焦点环 = 宿主蓝不动（Tab 试试）。

现状 → 目标 →
红线回显（实施时逐条自查）：无 animation 声明（扫描线为静态纹理）；按压位移是唯一新增 transition（80ms，reduced-motion 归零）；硬阴影只有 2px 2px 0 一档，出现在进行中卡 / 托盘 / 黄按钮 / LCD 框四处；3px+ 粗线、机脊红铺底、像素字体、LED 闪烁不做； chip 与 mainPanel 壳零渗透；黄只在「一等选中 + 主行动」，表单控件内部选中保持宿主蓝；暗色下 LCD/纸色走配对值（best-effort），黄与墨线天然双主题安全。
