# 《宝可梦来敲门》桌宠待办系统 — 实施计划

## 技术选型
- **Tauri 2 + Rust**：桌宠窗口（透明、无边框、置顶、可拖拽/点击穿透）+ 后台任务（网络、定时、同步）全在 Rust 侧，常驻内存 ~40MB。
- **前端 Vue 3 + TypeScript + Vite**：宠物动画（CSS/SVG sprite）与主面板 UI。
- **本地存储 SQLite**（rusqlite）：任务、分类、宝可梦映射、同步状态、设置，全部本地优先。
- **AI**：OpenAI 兼容适配层（可配置 base URL + API Key + 模型名，兼容 DeepSeek/GLM/Kimi 等）。

## 核心架构
两个窗口 + 一个 Rust 后台服务：
1. **桌宠窗口**：常驻桌面，当前任务气泡显示"皮卡丘正在陪你做：xxx"，快捷按钮（暂停/完成/换一个）。宠物按任务类型切换（见映射）。
2. **主面板窗口**：任务管理（今日/排期/收件箱）、IM 消息审核、宝可梦分配、设置。
3. **Rust 后台**（tokio）：飞书轮询、AI 分类、Todoist 双向同步、提醒调度，全部带重试与离线队列，UI 卡死不影响后台。

## 数据模型（SQLite）
- `tasks`：id、标题、分类、优先级、状态(收件箱/已排期/进行中/已暂停/完成)、截止/提醒时间、番茄计时、来源(本地/飞书/Todoist)、外部 id。
- `categories`：6 类默认（工作/学习/生活/健康/社交/紧急），每类绑定一只宝可梦（可换）。
- `im_messages`：拉取的飞书消息缓存 + AI 分类结果 + 用户处理状态。
- `settings` / `sync_state`。

## ADHD 友好交互（针对 INTP/注意力缺陷）
- **唯一"当前任务"**：同时只高亮一个任务，桌宠身上常驻显示，随时可见自己在干嘛。
- **一键暂停/切换**：宠物气泡上直接点暂停、切换任务，切换不丢上下文（自动记录暂停时间）。
- **收件箱而非立即决策**：AI 从 IM 提取的待办先进收件箱，一条一条滑选"要/不要/改天再说"，降低决策负担。
- **宝可梦提醒分级**：普通提醒=宠物换装+气泡；紧急任务=对应宝可梦敲门动画+系统通知；超时未处理=宠物主动"催"。
- 番茄钟可选（默认 25min，可关）。

## 对接方案
- **飞书**：企业自建应用（免费），机器人拉进需要的群/会话，Rust 侧定时（默认 2min）调用 `im/v1/messages` 历史消息接口轮询增量拉取，无需公网回调服务器。新消息 → AI 分类 → 判断"是否包含待办/时间/承诺" → 生成建议进收件箱，用户确认后才建任务。
- **Todoist**：REST API v2，双向同步（本地为准合并，按 external_id 映射，冲突时弹卡片让用户选），免费版够用。
- **提醒**：Rust 调度器 + tauri-plugin-notification 系统通知 + 桌宠动画。

## 里程碑
1. **M1 骨架**：Tauri 工程搭建、SQLite、双窗口、任务 CRUD + 分类 + 宝可梦映射（先用开源 sprite 图，如 PokeAPI 素材，个人使用）。
2. **M2 专注模式**：当前任务显示、暂停/切换、番茄钟、桌宠动画状态机（ idle/工作/催促/敲门）。
3. **M3 提醒系统**：排期、系统通知、分级提醒。
4. **M4 飞书 + AI**：轮询拉取、OpenAI 兼容分类、收件箱确认流。
5. **M5 Todoist 双向同步**。
6. **M6 打包与稳定性**：macOS (dmg) / Windows (NSIS) 打包、CI（GitHub Actions 双平台构建）、崩溃日志（tauri-plugin-log）、自动重连/重试收尾。

## 性能与稳定性要点
- 常驻时只有桌宠窗口渲染，主面板关闭不退后台；网络轮询间隔可调，退避重试。
- 所有外部调用放 tokio 任务，超时+失败入队重试，断网可用（本地优先架构）。
- 日志本地滚动记录，便于排查。
